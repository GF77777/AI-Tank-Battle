# 坦克贴皮素材规范计划

## 概要

为 5 种坦克增加**可选 PNG 贴皮层**：`assets/tanks/` 下存在对应图片则用图片，缺失则回退现有代码矩阵。先贴一辆试水，机制按 5 种通用设计。纯视觉改动，RL 训练/评估零影响。

## 用户需要提供什么（素材规范）

| 项目 | 规格 | 原因 |
|---|---|---|
| 文件位置 | `assets/tanks/` 目录（新建，已加入交付） | 集中管理，与代码分离 |
| 文件命名 | `scout.png` / `standard.png` / `heavy.png` / `enemy.png` / `rusher.png` | 与 `player_tanks` 键、敌方两种一一对应；先贴一辆就只放一张 |
| 尺寸 | **28×28 像素**；接受 56×56 等整数倍（程序最近邻缩小） | 坦克渲染尺寸 `TANK_SIZE=28`（14×14×2） |
| 朝向 | **朝上**（炮管指向图片顶部） | 程序自动旋转出右/下/左，像素画 90° 旋转无损 |
| 背景 | 透明（RGBA PNG） | 战场黑底 + 地形叠加，白底会穿帮 |
| 画风 | 像素风、硬边无抗锯齿；车身居中、左右对称留白 | 与现有 FC 复古风格一致；碰撞盒是整个 28×28，对称居中保证转向不偏心 |
| 细节上限 | 主色 + 暗部描边 + 高光 + 1 个装饰色为宜 | 28×28 上超过 6 色会糊成色块 |

AI 生成图的后处理（如用豆包/SDXL 出图）：缩放到 28×28（最近邻，勿用双线性）、去背景为透明、必要时手工修边。

## 改动方案

### 1. `game/sprites.py`（唯一代码改动，约 30 行）

- 顶部加 `_SKIN_DIR = os.path.join(os.path.dirname(os.path.abspath(__file__)), "..", "assets", "tanks")`（相对本文件定位，任意 cwd 运行都能找到）。
- 新增 `_load_skin(name)`：
  - 路径 `_SKIN_DIR/{name}.png` 不存在 → 返回 `None`。
  - `pygame.image.load`；仅当 `pygame.display.get_surface() is not None` 时 `convert_alpha()`（兼容 headless 评估，避免 "no video mode" 报错）。
  - 尺寸非 28×28 → `pygame.transform.scale(img, (28, 28))`（pygame 的 scale 即最近邻，像素不糊）。
- `_tank_set` 重构为接受"朝上 surface"：`_tank_set_from_surface(up)` 旋转出四方向；原 `_tank_set(palette, template)` 改为内部先 `_make_surface` 再复用同一旋转逻辑。
- `Sprites.__init__`：5 种坦克逐一 `_load_skin(name)`，命中用皮肤、未命中用现有矩阵（调色板/模板代码全部保留作回退）。映射：`scout/standard/heavy → player_tanks`，`enemy → enemy_tank`，`rusher → enemy_tank_rusher`。
