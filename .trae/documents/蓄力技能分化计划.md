# 蓄力技能分化计划（轻骑疾冲 / 重装冲击波）

## 1. 需求

三型号蓄力技分化（当前三型号共用同一发穿甲弹）：

| 型号 | 普攻（v1.6 已上线） | 蓄力技（本次） |
|---|---|---|
| 标准 | 单发·全图 | **穿甲弹（保持不变）** |
| 轻骑 | 自动二连发·半图 | **冲锋疾冲**：向朝向疾冲 3 格，撞碎砖墙、撞杀敌人 |
| 重装 | 扇形冲击·1/4 图 | **全向冲击波**：360° 范围伤害，半径同扇形（104px） |

约束：RL 环境固定标准型且标准型不变 → 训练/评估基线逐位不变；蓄力技仍仅人类模式（`start_charge` 本就只在人类入口调用）。

### 3.3 [core.py](file:///c:/Users/CJP/Desktop/AI坦克大战/game/core.py)

**`release_fire` 改为按蓄力技分发**（未满仍走普攻）：

```python
def release_fire(self):
    if not self.charging: return
    full = self.charge_frames >= self.player.charge_frames_max
    self.charging = False
    self.charge_frames = 0
    if not full:
        self.player_fire()
        return
    skill = self.player.charge_skill
    if skill == "dash":
        self._dash()
    elif skill == "shockwave":
        self._shockwave()
    else:
        self.player_fire(piercing=True)
```

**新增 `_dash()`（轻骑）**：从当前位置沿朝向按 4px 步进，最多 `dash_tiles*TILE_SIZE`(96px)；每步：
- 出界或 `rect_hits_tiles(rect, {STEEL, RIVER, BASE})` → 停止（砖不在阻挡集：撞碎继续）
- 该步 rect 覆盖的砖 → `grid=EMPTY` + `_add_flash`
- 覆盖到的敌人：`invincible<=0` → `_on_enemy_killed`；`invincible>0`（出生保护）→ 停止（不撞无敌单位，避免重叠）
- 步进成功才更新 `p.x/p.y`
结束后：`p.fire_cooldown = p.charge_cooldown`、`audio.play("shoot", 0.7)`、`shake=4`、目的地加一个闪光环。**不给额外无敌帧**（风险即收益，手感反馈再议）。

**`_fan_fire` 拆出伤害核心 `_blast_damage(px, py, fx, fy, radius, cos_limit)`**：`_fan_fire` 保留冷却/音效/`fan_flash` 后调用它（cos_limit=cos30°）；原逻辑不变。

**新增 `_shockwave()`（重装）**：冷却 42 + `audio.play("explosion", 0.9)` + `shake=6`，调用 `_blast_damage(..., cos_limit=-1.0)`（全向），并 `rings.append({"x","y","timer":10,"total":10,"r0":20,"r1":104,"w":3})`。

**闪光环渲染泛化**：`rings` 条目支持 `r0/r1/total/w`（默认 16/28/8/2，拾取环生成处补默认键）；渲染 `radius = r0 + (1-timer/total)*(r1-r0)`、`width=w`，颜色不变。

**文案** `_TEXTS`：
- `tank_desc_scout` →「自动二连发·射程半图，蓄力疾冲破障」/ "Burst fire, half range; charge to dash"
- `tank_desc_heavy` →「扇形近战清场，蓄力全向冲击波」/ "Fan blast; charge for 360° shockwave"

## 4. 假设与决策

- 疾冲不跨河/不穿钢/不撞基地（与坦克移动阻挡一致），撞无敌期敌人会被挡停；不附带无敌帧。
- 疾冲/冲击波后冷却 = 现有 `charge_cooldown`(42)；冲击波半径与扇形相同 104px；疾冲距离 3 格。
- 冲击波与扇形同规则：不伤己方基地、不毁钢板、无视遮挡。
- 音效复用现有 shoot/explosion，不新增素材。
