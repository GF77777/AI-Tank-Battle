# 对战模式计划（竞技场 1v3 大混战）

## 概要

标题菜单新增第 5 项「对战模式」：对称竞技场地图（外圈钢板 + 中央十字砖 + 四角 L 形掩体，无基地），玩家 + 3 个由现有 `models/dqn_tank.pth` 驱动的 AI 坦克**真·大混战**（互相攻击），每方 3 条命消耗战，玩家最后存活=胜利、命尽=失败。闯关模式与 RL 管线完全不动。

**用户已确认的决策**：真大混战（AI 互打）、3 个 AI、保留闯关、用现有 DQN 模型、3 条命消耗战。

- `update()`：
  - 敌人循环分支：`if self.versus and getattr(e, "kind", None) == "foe"` → DQN 驱动：每 `S.FRAME_SKIP` 帧 `obs=build_foe_state(self, e, 其他存活坦克)` → `agent.act(obs, 0.0)` → 解码存 `e.vs_action`；每帧应用（`set_direction`/`move_tank`/开火走 `_versus_foe_fire(e)`）；否则走原 `update_ai`。
  - 淘汰复活：foe 死亡且 `lives > 0` → `respawn_timer` 倒数到 0 回出生角复活（invincible=120）。
  - `_update_spawning` / `_update_pickup_timer` 仅 `not self.versus` 时执行；`_update_pickups` 保持（对战不掉道具，`_maybe_drop_pickup` 加 `not self.versus` 门）。
  - `_check_win` 加门：闯关条件仅 `not self.versus`；对战胜利 = 全部 foe `lives <= 0` 且 dead → `_end(True)`。
- `_versus_foe_fire(foe)`：冷却 21 帧、按 owner 计数 ≤2 发；子弹 `from_player=False`、`owner=foe`。`_fire_bullet`（玩家）补 `b.owner = self.player`。
- `_update_bullets` 对战分支（`if self.versus`）：
  - 子弹互消：任意两发 `owner` 不同且相撞 → 同归于尽（替代原玩家弹/敌方弹二分）。
  - 子弹打坦克：目标 = 玩家 + 存活 foe；跳过 `b.owner`；无敌期吸收；命中 → `_on_player_hit()`（玩家）或 `_on_foe_killed(e, by_player=b.owner is self.player)`。
  - 闯关分支原样保留。
- `_on_foe_killed(foe, by_player)`：爆炸+闪白+震屏+音效；`by_player` 时 score/kills 各 +100/+1；`foe.lives -= 1`；>0 则 `respawn_timer = 60`，否则淘汰。
- `_on_player_hit`：复活点改为 `VERSUS_PLAYER_SPAWN if self.versus else S.PLAYER_SPAWN`。
- `_blast_damage` / `_dash` 杀到 `kind=="foe"` 的敌人时走 `_on_foe_killed(e, True)`；其余走 `_on_enemy_killed`。
- 结算 Enter：WIN 时 `if self.versus: _start_versus()`（重开一局，不进 `_next_level`）；LOSE Enter 现有重开逻辑改走 `_start_versus`（`self.versus` 时）。
- `back_to_title` / `start_game`：`_reset_battle(0)` 默认 versus=False，自动清空。
- 渲染 `_render_field`：敌人循环对 `kind=="foe"` 用灰白敌方精灵，并在头顶 8px 处画 12 号 `S.RED` 字母 tag（A/B/C）区分三个 AI。

## 假设与决策

- AI 对手固定 standard 型、不吃道具、不蓄力（DQN 动作空间无蓄力）——与训练分布一致。
- 基地槽恒 0 属于轻微分布偏移，接受（用户已选「先用现有模型」）。
- 对战模式无基地、无道具、无砖墙扰动（竞技场固定公平）；胜利结算复用现有界面（分数=击杀×100）。
- RL 零接触：`env.py` 从不设 `versus=True`；基线必须逐位一致。
