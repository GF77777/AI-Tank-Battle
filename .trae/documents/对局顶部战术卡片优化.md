# 对局顶部「战术卡片」优化计划

## Summary
按用户选择，将对局顶部 HUD 优化为与设置、坦克营地一致的深色战术卡片风格。保留现有 48px 高度、战场尺寸和全部信息，不新增积分、击杀或计时等数据。

## Current State Analysis
- [core.py 的 `_render_hud()`](file:///c:/Users/CGF/Desktop/AI坦克大战/game/core.py#L1956-L1981) 当前直接在深色顶栏绘制“剩余 + 坦克图标 + 数量”；仅排位模式在右侧绘制“安全区 + 倒计时”。
- [settings.py](file:///c:/Users/CGF/Desktop/AI坦克大战/game/settings.py#L4-L29) 已统一提供 `HUD_HEIGHT=48`、`HUD_BG`、`PANEL_BG`、`PANEL_BORDER`、黄色和红色等基础样式。
- 顶栏图标已有 `_icon()` 缓存；战场从 `HUD_HEIGHT` 以下开始，镜头、小地图和技能圆环均独立渲染。
- 截图中的问题是标签、图标与数字像散排文本，缺少与现有页面一致的分组、描边和强调层级。

## Proposed Changes
### `game/core.py` — 仅调整 `_render_hud()`
1. **保留顶栏骨架**
   - 继续使用 `S.HUD_BG` 填充 `S.HUD_HEIGHT` 高的顶部区域。
   - 底部分隔线改用统一的 `S.PANEL_BORDER`，不改变高度和战场起点。

2. **左侧“剩余敌人”卡片**
   - 使用 `Rect(6, 6, 126, 36)`，深色面板底、1px `PANEL_BORDER` 描边、4px 圆角。
   - 卡片左侧增加 2px 黄色竖向强调条，呼应现有按钮选中态。
   - “剩余”标签使用 12px、`LIGHT_GRAY`；坦克图标调整为 18px；数量使用 20px 粗体白色并右对齐。
   - 标签、图标和数字均按卡片垂直居中，图标位置根据标签宽度计算，兼容中文与英文回退文本。
   - 存活敌人数继续沿用 `sum(1 for f in self.versus_foes if f.alive)`，不改统计口径。

3. **右侧“安全区”卡片**
   - 仅在 `battle_mode == "versus"` 时绘制；对战、自定义模式不增加额外信息。
   - 使用相同的深色面板底、描边和圆角，以红色竖条强调危险状态。
   - 宽度按“安全区”标签与 `ZONE n s / ZONE MAX` 文本实际宽度计算，并设置合理最小宽度；右边距保持 6px。
   - 标签使用 12px 灰色，倒计时沿用 16px 红色，二者垂直居中、值右对齐。

4. **保持不变**
   - 不修改 `game/settings.py` 的屏幕、HUD、镜头或颜色常量。
   - 不修改战场、迷雾、小地图、公告、击杀播报、技能圆环、暂停与结算。
   - 不新增资源文件，不修改玩法状态、AI 观测或训练逻辑。

## Assumptions & Decisions
- 用户已明确选择「战术卡片」，并要求战场尺寸与现有信息保持不变。
- 本次截图中的“顶部”指对局 HUD，不调整首页顶部标题或玩家信息。
- 卡片样式直接复用现有颜色与字体函数，避免引入新的 UI 框架或素材。
