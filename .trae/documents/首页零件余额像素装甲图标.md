# 首页零件余额像素装甲图标计划

## Summary

- 去掉首页顶栏“零件 / PARTS”文字，只保留“图标 + 黄色余额数字”。
- 采用已选定的 **D 像素装甲** 方案：16×16、像素直角、黄色主体、透明铆钉与加强筋镂空。
- 沿用项目的代码矩阵精灵方式，不新增图片素材，不改变零件余额、奖励或存档逻辑。

## Current State Analysis

- `game/core.py:2329-2339` 当前在首页顶栏右侧依次绘制灰色 `T("parts")` 标签、程序绘制的四向齿轮和黄色数字。
- `T("parts")` 还用于名片页与结算页（`game/core.py:2592`、`game/core.py:2715`），因此不能删除文案表中的 `"parts"`，只需停止在首页顶栏渲染它。
- `game/sprites.py:310-321` 已有 `_make_surface()` 字符矩阵生成与逐行长度校验；`game/sprites.py:498-578` 的 `Sprites` 单例负责缓存精灵，可直接承载新图标。
- 项目风格为 FC 8-bit 复古像素，逻辑分辨率 416×464、窗口 2 倍最近邻放大；主强调色必须复用 `settings.py:25` 的 `S.YELLOW = (240, 200, 60)`，不新增颜色。

## Proposed Changes

### 1. 在 `game/sprites.py` 增加像素装甲精灵

- 在其他 16×16 图标矩阵附近新增 `_PARTS_ICON`，使用 `Y` 表示黄色、`.` 表示透明；最终矩阵固定为：

```python
_PARTS_ICON = [
    "................",
    "...YYYYYYYYYY...",
    "...YYYYYYYYYY...",
    "...YYYYYYYYYY...",
    ".YYY..YYYY..YYY.",
    ".YYY..YYYY..YYY.",
    ".YYYYYY..YYYYYY.",
    ".YYYYYY..YYYYYY.",
    ".YYYYYY..YYYYYY.",
    ".YYY..Y..Y..YYY.",
    ".YYY..Y..Y..YYY.",
    ".YYYYYY..YYYYYY.",
    ".....YYYYYY.....",
    ".....YYYYYY.....",
    ".....YYYYYY.....",
    "................",
]
```

- 造型含义：上方为装甲板主体，四个 2×2 透明孔为铆钉，中间 2px 透明竖槽为加强筋，下方收窄形成装甲安装边。
- 新增 `_PAL_PARTS = {"Y": S.YELLOW}`，直接引用现有调色板。
- 在 `Sprites.__init__()` 中创建 `self.parts_icon = _make_surface(_PARTS_ICON, _PAL_PARTS, 1)`，得到透明底 16×16 Surface；由现有 `_make_surface()` 校验每行长度。

### 2. 调整 `game/core.py` 首页顶栏绘制

- 保留余额数字的现有计算：`get_font(18)`、`S.YELLOW`、右侧 12px 边距以及 `pygame.Rect` 之外的现有布局均不变。
- 删除 `_render_start()` 中旧齿轮的 4 个齿块、2 个圆形，以及首页顶栏的 `lab` 标签创建与 `blit`。
- 复用现有 `_icon()` 缓存：`self._icon("parts", sprites.parts_icon, 16)`。
- 图标绘制在 `(px - 20, 14)`：图标宽 16px，与数字间隔 4px，垂直中心仍为 y=22；数字继续绘制在 `(px, 13)`。
- 修改后首页顶栏视觉顺序固定为“像素装甲图标 → 4px 间隔 → 余额数字”，整体随数字宽度右对齐。

### 3. 明确不改动的范围

- 不删除 `_TEXTS["parts"]`，名片页和结算页仍显示“零件 / PARTS”。
- 不修改 `settings.py`、零件奖励规则、存档结构、其他 HUD、菜单或页面。
- 不新增外部图片、字体、依赖或文档。

## Assumptions & Decisions

- 用户已在 A 六角螺母、B 八角齿轮、C 十字螺钉、D 像素装甲中选择 **D**。
- “去掉零件二字”仅指上传截图对应的首页顶栏，不影响其他需要说明余额含义的页面。
- 镂空必须透明，让首页墨蓝背景自然透出；不能用黑色实填代替。
- 图标本身保持 16×16 逻辑像素，最终由项目现有 2 倍最近邻输出为 32×32 窗口像素，避免平滑缩放导致模糊。
