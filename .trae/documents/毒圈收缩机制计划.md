# 毒圈收缩 MVP 实施计划

## Summary

**最小可玩版毒圈**：开局 10s 全图安全，之后每 15s 安全区向中心缩一圈（半径 6→0），圈外每 1.5s 扣 1 格血（无视无敌/护盾），圈外格子变红，HUD 一行倒计时。强制遭遇战，治 AI 苟活。

RL 状态 260→**262 维**（+圈半径、+收缩倒计时）——保留，因为 AI 不知道圈在哪就永远学不会进圈，这是闭环必需。

**明确缓做**（后续迭代）：百分比血量制、伤害差异化、收缩预警闪烁、血条美化、文档精修。

**新增 3 个方法**（放 `_apply_item` 之后）：
```python
def _in_zone(self, tank):
    """坦克中心格是否在安全区内（Chebyshev 距离 <= zone_radius）。"""
    c = int((tank.x + S.TANK_SIZE / 2) // S.TILE_SIZE)
    r = int((tank.y + S.TANK_SIZE / 2) // S.TILE_SIZE)
    ctr = S.MAP_ROWS // 2
    return max(abs(r - ctr), abs(c - ctr)) <= self.zone_radius

def _update_zone(self):
    """毒圈：倒数收缩 + 圈外按节拍扣血（无视无敌/护盾）。"""
    if self.zone_radius > 0:
        self.zone_timer -= 1
        if self.zone_timer <= 0:
            self.zone_timer = S.ZONE_SHRINK_INTERVAL
            self.zone_radius -= 1
    self.zone_tick = (self.zone_tick + 1) % S.ZONE_TICK_FRAMES
    if self.zone_tick != 0:
        return
    for t in [self.player] + self.versus_foes:
        if t.alive and not self._in_zone(t):
            self._zone_damage(t)

def _zone_damage(self, tank):
    """圈外扣血：不算人头，淘汰照常爆炸 + 掉道具。"""
    tank.hp -= 1
    self._add_flash(tank.rect)
    if tank.hp > 0:
        return
    self.explosions.append(Explosion(tank.x + S.TANK_SIZE // 2, tank.y + S.TANK_SIZE // 2))
    self.audio.play("explosion", 0.6)
    if tank is self.player:
        self.lives -= 1
        tank.alive = False
        self.lose_reason = "life"
        self._end(False)
    else:
        tank.alive = False
        tank.lives -= 1
        self._drop_item(tank)
```

**`update()`**：`self._update_items()` 后加一行 `self._update_zone()`。

## Assumptions & Decisions

| 决策 | 理由 |
|---|---|
| 缓做百分比血量/预警闪烁/血条美化 | 用户指示先跑 MVP；毒圈闭环不依赖它们 |
| 保留 RL +2 维 | AI 不知圈在哪就学不会进圈，闭环必需 |
| 方形圈 Chebyshev | 判定一个 max()，渲染按格覆盖 |
| 圈外扣血无视护盾、不算人头、照常掉道具 | 防护盾苟圈外；归因不清不给击杀奖；掉落规则一致 |
| HUD 一行文字倒计时 | 玩家需要知道何时缩圈；一行 render 成本最低 |
