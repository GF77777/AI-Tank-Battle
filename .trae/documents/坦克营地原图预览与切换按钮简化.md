# 坦克营地原图预览与切换按钮简化

## 目标

1. 提高轻骑、标准、重装三款坦克营地大图的清晰度和视觉占比。
2. 删除底部三个型号切换按钮中的坦克缩略图，型号名称恢复单独居中。
3. 不改变战斗精灵尺寸、坦克属性、选用状态及键鼠交互。

## 当前状态

- `game/sprites.py` 的 `_load_skin()` 会把 `assets/tanks/` 下的 28×28 PNG 先缩成 `S.TANK_SIZE = 21` 的战斗精灵。
- `game/core.py` 的 `_render_garage()` 又取该 21×21 精灵放大 5 倍至 105×105。非整数比例缩小损失的像素细节无法通过再次放大恢复。
- 三张原始 PNG 均为 28×28 透明素材，适合直接进行整数倍最近邻放大。
- 底部卡片目前绘制 16×16 缩略图，并用 `group_w/group_x` 对图标和文字整体居中；这些缩略图是本次需要删除的内容。

## 修改方案

### 1. 保留营地专用原始坦克资源

文件：`game/sprites.py`

- 调整 `_load_skin()`，加载并转换 PNG 后直接返回原始尺寸，不再提前缩到 21×21。
- 在 `Sprites.__init__()` 初始化三款玩家坦克时，统一取得原始朝上资源：
  - PNG 存在：使用加载的 28×28 原图。
  - PNG 缺失：使用 `_make_surface(template, palette, 2)` 生成同尺寸代码矩阵回退图。
- 新增 `self.garage_tanks`，按 `scout / standard / heavy` 保存上述原始朝上资源，仅供营地预览使用。
- `self.player_tanks` 仍通过 `_tank_set_from_surface()` 生成，继续由 `_fit(..., S.TANK_SIZE)` 得到 21×21 四方向战斗精灵；`self.player_tank` 兼容引用保持不变。

### 2. 营地改用原图整数倍放大

文件：`game/core.py`，`_render_garage()`

- 将预览来源由 `sprites.player_tanks[tt][S.UP]` 改为 `sprites.garage_tanks[tt]`。
- 使用最近邻 `pygame.transform.scale()` 将 28×28 原图放大 4 倍至 112×112，替代当前 21×21 → 105×105 的缩放链路。
- 大图继续在预览面板内水平居中，纵向从 `184 + dy` 开始；八角展台纵向范围同步调整为 `184 + dy` 至 `296 + dy`，使展台承托完整大图。
- 保留现有蓝灰展台、深色地台、预览序号、状态文字和整页垂直居中公式，不增加亮描边或其他装饰。
- 预览面板、`garage_select` 命中区及其余页面布局不变。

### 3. 删除底部切换按钮图标

文件：`game/core.py`，`_render_garage()` 底部型号卡片循环

- 删除 `thumb`、`group_w`、`group_x` 及缩略图 `blit`。
- 型号名称按 `card.centerx - card_name.get_width() // 2` 单独水平居中，纵坐标仍为 `card.y + 5`。
- 保留下方“使用中 / 已拥有”、黄框预览状态、绿字出战状态和三个卡片命中区。

## 决策与约束

- 不修改全局 `S.TANK_SIZE`，避免影响战斗碰撞、HUD 和其他界面图标。
- 不修改三张 PNG 素材，仅修正营地预览的资源选择与缩放方式。
- 不重复加载同一张 PNG；原始资源同时作为营地预览和战斗精灵的生成来源。
- 保留缺图时代码矩阵回退能力。

## 验证

1. 运行 `python -m compileall main.py game`，确认语法通过。
2. 使用 `SDL_VIDEODRIVER=dummy`、`SDL_AUDIODRIVER=dummy` 做无窗口渲染：
   - 依次切换轻骑、标准、重装，确认营地均可正常绘制。
   - 断言三款营地源图均为 28×28，战斗朝上及四方向精灵仍为 21×21。
   - 确认 112×112 大图、展台、状态文字均位于预览面板内且无重叠。
   - 检查底部按钮仅显示居中的型号名称与状态文字。
3. 回归 A/D、方向键、Enter、卡片点击、预览点击、返回按钮和 Esc，确认选用逻辑与命中区不变。
4. 通过临时替换资源加载函数模拟 PNG 缺失，确认三款代码矩阵回退预览正常，且不改动实际素材。
5. 将三款临时验证截图写入系统临时目录，检查完成后删除，不在工作区留下测试产物。
