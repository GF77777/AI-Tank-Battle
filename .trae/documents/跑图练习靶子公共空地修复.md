# 跑图练习靶子公共空地修复

## 目标

将跑图练习中固定生成的 4 个靶子全部放在三张地图的公共空地，避免坦克生成在砖墙等特殊地块内。

## 当前状态与根因

- `game/level.py` 的三张地图使用 `. = EMPTY`、`B = BRICK`、`S = STEEL`、`R = RIVER`、`F = FOREST`。
- 玩家与 AI 的随机出生由 `generate_spawns()` 生成，候选点已限制为 `EMPTY`，不是本次卡地形的来源。
- `game/core.py` 的 `_spawn_roam_dummies()` 使用固定坐标 `(8,8)、(14,8)、(8,2)、(14,2)`，未检查地形：
  - `(8,8)` 在 MAP_1 / MAP_2 / MAP_3 分别为 `B / . / B`。
  - `(14,2)` 在三张地图均为 `B`。
  - `(14,8)`、`(8,2)` 在三张地图均为空地。
- 三张地图共有 184 个公共空地，可直接选择靠近原布局的公共空地替换错误坐标。

## 修改方案

文件：`game/core.py`，`_spawn_roam_dummies()`

将固定靶子坐标改为：

```python
((8, 7), (14, 8), (8, 2), (14, 1))
```

- `(8,8) → (8,7)`：向上移动一格，避开 MAP_1 和 MAP_3 的中心砖墙。
- `(14,2) → (14,1)`：向上移动一格，避开三张地图共有的砖墙。
- 其余两个正确位置保持不变。
- 添加简短注释，说明这四个位置在三张地图均为公共空地。

不修改地图数据、`tile_to_px()`、随机出生算法、坦克移动碰撞、靶子数量及重建逻辑。

## 决策与约束

- 采用静态公共空地坐标，保持修改最小；实施时逐图验证，不引入新的出生点抽象。
- 只修复跑图练习的固定靶子，不扩大为移动碰撞或 AI 寻路调整。
- 森林虽可通行，本次仍统一选择 `.` 空地，避免靶子生成在任何特殊地块上。

## 验证

1. 运行 `python -m compileall main.py game`。
2. 对 MAP_1 / MAP_2 / MAP_3 分别启动跑图练习：
   - 确认生成 4 个靶子，顺序与标签不变。
   - 确认四个目标格在三张地图全部为 `EMPTY`。
   - 将靶子格转换为 `PlayerTank.rect`，确认不与砖墙、钢板、河流、森林或基地重叠。
   - 确认靶子全部位于地图边界内，并能正常渲染。
3. 对三张地图的随机出生进行多次采样，确认玩家与 AI 出生点仍全部为空地，验证本次修改未影响其他模式。
