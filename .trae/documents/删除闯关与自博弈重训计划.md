### 7. `game/env.py` — 重写为 VersusEnv（自博弈）

```python
"""VersusEnv：对战竞技场自博弈 RL 环境。学习者=game.player，3 个对手共用同一 agent。"""
STATE_DIM = 248  # 布局不变，由 build_foe_state 产出

class VersusEnv:
    def __init__(self): ...
    def set_opponents(self, agent): self.game.foe_agent = agent
    def reset(self):
        self.game._reset_battle(); self.game.state = STATE_PLAYING
        self.decision_steps = 0; self._kills0 = 0; self._lives0 = S.VERSUS_LIVES
        return self._state()
    def step(self, action, epsilon=0.0):
        self.game.foe_epsilon = epsilon          # 对手与学习者共享 ε（自博弈探索）
        direction, fire = decode(action)          # 复用现 _decode_action 逻辑
        for _ in range(S.FRAME_SKIP):
            if self.game.state != STATE_PLAYING: break
            self.game.update(input_dir=direction, input_fire=fire)
        reward = (game.kills - self._kills0) * S.VS_R_KILL + (self._lives0 - game.lives) * S.VS_R_DEATH + S.VS_R_STEP
        ...WIN+500 / LOSE-500 / MAX_DECISION_STEPS 截断...
        info = {"kills": game.kills, "win": ..., "steps": ..., "score": game.score, "truncated": ...}
```

- `build_foe_state` 保留不动；`_decode_action` 改为模块级函数（TankEnv 删除）。
- 不存对手 transition（标准自博弈简化，只学学习者视角）。

## 假设与决策

- 「观战 AI」菜单项随闯关一并删除；观战需求由重写后的 `play_ai.py`（4 AI 自博弈）承接。
- 学习者视角复用 `build_foe_state`（自身槽=玩家、对手 3 方占敌人槽、基地槽恒 0、子弹 owner 判 ±1），STATE_DIM=248 不变，网络结构 248→256→256→10 不变。
- 自博弈对手不冻结快照、不存对手经验——最简单可用的自我对弈（用户已选）；对手火力 = 学习者当前策略 + 同一 ε。
- 生命统一常量 `VERSUS_LIVES=3`（满足「玩家和对手默认 3 条」）。
- 试玩日志 playtest 保留（对战局照常记录）。
