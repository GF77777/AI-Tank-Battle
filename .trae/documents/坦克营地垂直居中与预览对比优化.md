# 坦克营地垂直居中与预览对比优化计划

## Summary

- 将坦克营地整组内容向上移动 42px，使页面顶部与底部留白均为 62px，在 416×464 逻辑画布中垂直居中。
- 在坦克后方增加蓝灰色八角展台，改善轻骑、重装暗色车身与深色背景的对比；不改变坦克原始配色和像素素材。
- 仅修改 `game/core.py` 的 `_render_garage()`，其他子页面、交互逻辑和属性数据不变。

## Current State Analysis

- 当前营地整组内容从主面板顶部 y=104 延伸至返回按钮底部 y=444，视觉中心为 y=274；屏幕中心为 y=232，因此整体偏下 42px。
- 水平方向主面板为 x=24、宽 368，在 416 宽画布中左右均为 24px，已经居中，无需调整 x 坐标。
- `game/core.py:2578-2690` 中面板、标题、预览、属性、型号卡和返回按钮均使用固定 y 坐标；预览、型号卡和返回按钮同时写入 `_hits`，移动时必须同步渲染矩形与命中矩形。
- `_page_title()` 已提供 `dy` 偏移参数（`game/core.py:2228-2233`），可只移动营地标题而不改其他子页。
- 当前预览背景接近 `S.PANEL_BG` 的近黑色，轻骑与重装车身也偏暗；现有坦克源尺寸 5 倍放大和像素轮廓应保留。
- 用户已选择“蓝灰展台”方案，不采用坦克亮描边。

## Proposed Changes

### 1. 营地整组内容上移并垂直居中

在 `_render_garage()` 开头设置局部 `dy = -42`，所有 y 坐标统一加上该偏移：

- 主面板改为 `(PANEL_X, PANEL_Y + dy, PANEL_W, PANEL_H)`，即顶部 104→62、底部 416→374。
- 标题调用改为 `_page_title(screen, "mode_garage", dy=dy)`，标题 116→74、分隔线 148→106。
- 页头零件图标和数字的 y 坐标分别使用 `TITLE_Y + dy + 4`、`TITLE_Y + dy + 5`。
- 预览卡和属性卡由 y=164 移至 y=122，高度、宽度和 x 不变。
- 预览内部坦克、椭圆、状态，右侧简介、分隔线、属性行、弹量，底部三型号卡、返回按钮与提示文字，全部在现有 y 表达式中追加 `dy`。
- 底部型号卡由 y=342 移至 300；返回按钮由 y=418 移至 376，按钮底部为 402；提示文字由 y=425 移至 383。
- 最终整组范围为 y=62…402，屏幕上下剩余空间分别为 62px 和 62px。
- 不修改全局 `PANEL_Y`、`TITLE_Y`、`TITLE_LINE_Y` 或其他页面常量，避免影响名片、设置等页面。
- `garage_select`、`garage_tank_*`、`garage_back` 继续使用移动后的同一份 Rect 写入 `_hits`，确保鼠标区域与视觉同步。

### 2. 增加蓝灰八角展台

在左侧预览卡内、坦克与地台之前绘制八角展台：

- 展台水平范围：`left = preview.x + 14`，`right = preview.right - 14`，宽 130px； tank 105px 宽，两侧保留约 12px 空隙。
- 展台垂直范围：`top = 188 + dy`，`bottom = 292 + dy`；上移后为 y=146…250。
- 八角切角为 12px，顶点依次为：上左、上右、右上、右下、下右、下左、左下、左上。
- 使用 `pygame.draw.polygon()`：填充复用现有网格蓝灰色 `(36, 49, 63)`，描边使用 `S.PANEL_BORDER`，宽 1px。
- 展台位于页码和黄色强调条下方，不覆盖它们；下移后的展台仍在预览卡范围内。
- 保留坦克源尺寸 5 倍最近邻放大，绘制位置只追加 `dy`，即坦克 y=142；展台覆盖坦克主体后方，炮管顶部可自然越过展台上沿。
- 原地台椭圆只追加 `dy`，并将颜色调整为深蓝灰 `(24, 30, 38)`，继续承担坦克底部阴影；绘制顺序固定为“八角展台 → 页码/强调条 → 椭圆地台 → 坦克 → 状态文字”。

### 3. 明确不改动

- 不修改 `sprites.py`、`settings.py`、坦克 PNG、像素矩阵、属性、文案或存档。
- 不增加坦克描边、发光、渐变或平滑缩放。
- 不改变卡片宽度、水平位置、字体层级和首页网格背景。
- 不改变 A/D、方向键、Enter、点击选用、Esc 和返回按钮行为。

## Assumptions & Decisions

- “整体向上移动，居中点”指整个营地页面组，而不是只移动左侧坦克；采用上下等距的 42px 上移量。
- “坦克在这个背景下不明显”通过局部浅蓝灰展台解决，不全局提亮面板，也不修改坦克素材。
- 八角造型比圆形光晕更贴合现有 FC 像素和战术面板风格。
- 本次仍只处理视觉布局，不增加新功能。
