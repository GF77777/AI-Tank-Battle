# 四边中点钢化 + 毒圈三轮制计划

## 目标

1. 三张图四边中点掩体 (0,8)(8,16)(16,8)(8,0) 由砖墙改为钢板（不可摧毁）。
2. 毒圈改三轮制：安全期 6s → 每轮 8s 一次性收缩到目标半径，8→5→2→0，第 3 轮后只剩中心 (8,8)。

## 现状分析（已探明）

- **地图**（game/level.py）：三张图 row0/row16 的 col8 为 `B`，row8 的 col0/col16 为 `B`；C4 校验 `(r,c)↔(c,16-r)`，四边中点恰为一个对称轨道 {(0,8),(8,16),(16,8),(8,0)}，同步改钢不破坏校验。用户原文的 (16,0)(0,16) 是出生角，已确认不动（本次改为四边中点方案）。
- **毒圈**（game/core.py L186-188, L827-841 + game/settings.py L119-122）：`zone_radius` 从 8 起每 480 帧（8s）减 1（共 8 次逐圈缩），`_in_zone` 用 Chebyshev 距离 ≤ radius 判定，radius=0 即只剩 (8,8)。HUD L1080 倒计时、渲染 L1142 红圈均基于 zone_radius。
- train/env 不直接引用收缩调度（env 只调 game.update），改调度零影响训练链。

## 改动方案

### 1. game/level.py — 三张图四边中点砖→钢

- row0 与 row16：`"........B........"` → `"........S........"`
- MAP_1 row8：`"B.......B.......B"` → `"S.......B.......S"`（中心 (8,8) 保持砖）
- MAP_2 row8：`"B....BB...BB....S"` → 即首尾 B→S：`"S....BB...BB....S"`
- MAP_3 row8：`"S....B..B..B....S"`
- 文件头注释「(0,8) 系掩体」措辞同步为「(0,8) 系钢板掩体」。

### 2. game/settings.py — 三轮调度常量

```python
ZONE_GRACE_FRAMES = 360          # 开局安全期 6s（不变）
ZONE_ROUND_INTERVAL = 480        # 每轮 8s 后一次性收缩
ZONE_ROUND_TARGETS = (5, 2, 0)   # 三轮目标半径：11×11 → 5×5 → 只剩(8,8)
ZONE_INITIAL_RADIUS = 8          # 不变
ZONE_TICK_FRAMES = 90            # 圈外 1.5s 扣 1 格（不变）
```
删除 `ZONE_SHRINK_INTERVAL`（仅 core.py L832 一处引用）。

### 3. game/core.py — 调度改造

- `__init__`（L186-188）：加 `self.zone_round = 0`（下一个目标下标）。
- `_update_zone`（L827-833）：收缩分支改为——
  ```python
  if self.zone_timer <= 0:
      if self.zone_round < len(S.ZONE_ROUND_TARGETS):
          self.zone_radius = S.ZONE_ROUND_TARGETS[self.zone_round]
          self.zone_round += 1
          self.zone_timer = S.ZONE_ROUND_INTERVAL
      # 最后一轮后 radius=0，timer 不再推进，圈不再缩
  ```
  注意 radius=0 时外层 `if self.zone_radius > 0` 已跳过，天然终止。
- HUD（L1080）：倒计时文案加轮次前缀——`f"ZONE {self.zone_round + 1}·{self.zone_timer // 60 + 1}s"`，radius≤0 仍显示 `"ZONE MAX"`。
- 渲染/伤害逻辑（L1142、L834-841）不动，自动适配新半径序列。

### 4. README.md — 一行级同步

毒圈描述改为「三轮收缩：6s 安全期后每 8s 一次性缩到 11×11 → 5×5 → 只剩中心，全程约 30s 进决赛圈」。

## 决策记录

- (16,0)(0,16) 是出生角，不改（用户已确认改四边中点方案）
- 三轮为**一次性跳缩**（8→5→2→0），不再是逐圈爬行；轮间 8s、圈外伤害节奏不变
- 出生直线遮挡反而增强：钢板不可被炸开
