# 窗口放大显示计划（2 倍整数缩放）

## 1. 概要（Summary）

当前游戏窗口只有 **416×464** 像素（13×13 格 × 32px + 48px HUD），在高分屏上显得很小。本次改动把窗口放大到 **832×928（固定 2 倍）**，用户体验上"页面更大"。

采用**渲染-放大**方案：游戏逻辑与渲染仍完全跑在 416×464 的逻辑分辨率上，最后一步把整帧整数放大 2 倍贴到窗口。这样：

* 像素美术、碰撞、物理手感、248 维状态向量、已训练模型**全部保持不变**，无需重训；
* 2 倍是整数缩放，最近邻取样，像素边缘依旧锐利（像素块实际变为 4×4，仍然清晰）；
* 不改逻辑分辨率，避免出现"地图变大、坦克变快/变慢、模型输入维度失配"等连锁问题。

已与用户确认：固定 2 倍、不支持拖拽改窗口大小。

## 3. 变更内容（Proposed Changes）

### 3.1 [settings.py](file:///c:/Users/CJP/Desktop/AI坦克大战/game/settings.py) — 新增窗口缩放常量

在"屏幕与网格"区块末尾（`FPS` 之后）追加：

```python

SCALE = 2                                        # 逻辑分辨率 -> 窗口的整数放大倍数
WINDOW_WIDTH = SCREEN_WIDTH * SCALE              # 832
WINDOW_HEIGHT = SCREEN_HEIGHT * SCALE            # 928
```

保留 `SCREEN_WIDTH/SCREEN_HEIGHT` 作为**逻辑分辨率**语义不变；所有逻辑、状态向量继续使用它们。

### 3.2 [core.py](file:///c:/Users/CJP/Desktop/AI坦克大战/game/core.py) — 新增显示工具函数

在文件末尾（`Game` 类之后）新增两个模块级函数，供两个入口复用，避免重复代码：

```python
def create_display(scale=S.SCALE):
    """创建固定尺寸窗口，并返回 (窗口 screen, 逻辑分辨率画布 logical)。"""
    screen = pygame.display.set_mode((S.SCREEN_WIDTH * scale, S.SCREEN_HEIGHT * scale))
    logical = pygame.Surface((S.SCREEN_WIDTH, S.SCREEN_HEIGHT))
    return screen, logical


def present(screen, logical):
    """把逻辑画布整数放大后贴满窗口（最近邻取样，像素保持锐利）。"""
    pygame.transform.scale(logical, screen.get_size(), screen)
```

说明：`pygame.transform.scale` 默认最近邻，2 倍放大不产生模糊；`Game.render()` 签名与实现均不改。

### 3.3 [main.py](file:///c:/Users/CJP/Desktop/AI坦克大战/main.py) — 人类玩家入口改用窗口 + 逻辑画布

## 4. 关键假设与决策（Assumptions & Decisions）

1. 窗口 = 逻辑分辨率 × 2 = 832×928，固定不可拖拽（用户已确认）。
2. 放大放在"呈现"这一步，不提升逻辑分辨率；因此物理手感、奖励、状态向量、已训练模型全部兼容，无需重训。
3. HUD 中文/英文文字随整屏一起放大 2 倍，观感为复古像素风；不额外做"高分字体"渲染。
4. 不做黑边/自适应/全屏/拖拽缩放等额外能力（用户明确选择"固定尺寸"）。
5. 若小屏设备上 928px 高度超出可视区，属于已知取舍，本次不处理。
