# 坦克仓库计划（标题界面车库：展示 + 选用）

## 1. 需求

标题界面新增第 4 个菜单项「坦克仓库」：进入后可翻页浏览 3 辆玩家坦克（轻骑/标准/重装）的大图、参数与技能说明；按 Enter 直接把当前页坦克选为闯关用坦克，Esc 返回标题。

决策（已确认）：仅玩家坦克（不展示敌方）；交互 = 展示 + 可选用车。

## 2. 现状（已探明）

- 标题菜单：[core.py](file:///c:/Users/CJP/Desktop/AI坦克大战/game/core.py) `MODE_CAMPAIGN/WATCH/CURVE = 0/1/2`，`_render_start` 用 `_menu_button` 循环 3 项（y=208+i*36），面板 `(24,72,368,340)`，hint y=336、move_hint y=364、footer y=392。
- 子视图模式：`start_notice` / `tank_select` 标志互斥、复用 START 状态不加新状态机状态；`tank_index` 跨进入记忆光标；Esc 有 `tank_select` 退出分支；`_confirm` 按 mode_index 分发。
- 精灵：`sprites.player_tanks[type][S.UP]` 28×28（贴皮后同样接口），HUD 图标已按型号取。
- 参数：`S.TANK_TYPES[type]` 内含 speed/fire_cooldown/max_bullets/charge_frames/fire_mode/charge_skill 等；说明文案在 `_TEXTS` 的 `tank_desc_*`。
- 选用链路：`self.tank_type`（默认 standard）→ `_reset_battle` 创建 `PlayerTank(px, py, self.tank_type)`；闯关模式 Enter → `tank_select=True` → 再 Enter 才 `start_game()`（车库选用不改变此流程，只是预选）。

### 3.4 输入
- `handle_event` 方向键分支：garage 时 左/右（也兼容上/下）→ `garage_index = (garage_index ± 1) % 3`

- `_confirm` START 分支：`MODE_GARAGE → self.garage = True`；garage 中 Enter → `self.tank_type = TANK_ORDER[garage_index]` + `self.tank_index = garage_index`（与选择视图光标同步）+ 音效，**留在车库继续浏览**（Esc 返回）

- `mode_garage`、`garage_title`、`hint_garage`（中英双份）、`in_use`（「·使用中」/"·IN USE"）

## 4. 假设与决策

- 车库不加新状态机状态（复用 START + 标志互斥，与 start_notice/tank_select 同模式）
- 翻页用左右键为主、上下键兼容；Enter 选用后留在车库，Esc 返回标题
- 车库只读 `S.TANK_TYPES` 参数，不复制数据；大图直接放大现有精灵（含贴皮）
- 闯关前的 tank_select 视图保留不动（车库选用 = 预选，进闯关仍可改）
