# 总音量与音效音量设置计划

## Summary

在标题与暂停共用的设置页中，保留现有音乐/音效开关，新增“总音量”和“音效音量”两行。两者均为 **0～100%**、步进 **10%**，支持 A/D、左右方向键及鼠标点击行左右半区调整，并持久化到 `prefs.json`。

默认两项均为 100%，保持当前响度不变。最终播放音量采用“现有基础增益 × 总音量 × 音效音量 × 事件音量系数”；不新增 BGM，不改变战斗、AI 或 RL 逻辑。

## Current State Analysis

- `game/audio.py:11` 的 `_MASTER_VOLUME = 0.45` 是固定基础增益；`game/audio.py:122-134` 在每次播放的 Channel 上设置 `_MASTER_VOLUME * volume`，目前没有可调总音量或音效音量。
- `game/audio.py:69-70,115-120` 只有 `music_on/sfx_on`；音乐开关是当前无 BGM 的占位，所有现有声音都由 `play()` 作为音效播放。
- `game/prefs.py:6-27` 通过默认值补齐与类型检查读取偏好，尚无音量字段；保存会覆盖整份 `prefs.json`，因此保存出口必须同时写入新增字段。
- `game/core.py:262-269` 启动时只恢复开关；`game/core.py:475-486` 的 `_save_profile()` 是设置统一保存出口。
- 当前设置索引为 0音乐、1音效、2人数、3对手名字、4键位、5返回。键盘、确认、悬停和点击分别分布于 `game/core.py:651-693,733-843,911-922`，新增行后必须同步全部分支。
- `game/core.py:2768-2805` 设置页现有 6 行，行高 30、行距 36；直接增至 8 行会超出面板。面板与提示位置为 `PANEL=(24,104,368,312)`、`LIST_Y0=160`、`HINT_Y=392`。
- `main.py` 只转发事件，无需增加音量控制逻辑。

## Proposed Changes

### 1. 增加两级音量及持久化

文件：`game/audio.py`、`game/prefs.py`

- `Audio` 在初始化音频设备前设置 `master_volume=100`、`sfx_volume=100`，保证无音频设备时属性仍可读取和调整。
- 新增 `set_master_volume(value)`、`set_sfx_volume(value)`，将输入转换为整数并钳制到 0～100。
- 保留 `_MASTER_VOLUME=0.45` 作为基础增益，Channel 音量改为：
  `_MASTER_VOLUME * master_volume / 100 * sfx_volume / 100 * volume`。
- 保留 `sfx_on` 硬开关及现有 Channel 独立音量机制；100%/100% 时与修改前响度一致，任一音量为 0% 时后续播放静音。
- `prefs._DEFAULT` 新增 `master_volume: 100`、`sfx_volume: 100`。加载时缺键或类型错误回默认值；针对 JSON 布尔值也是 Python `int` 子类的情况，音量字段显式拒绝 bool，再钳制至 0～100。旧配置无需主动改写，下次正常保存时补齐字段。

### 2. 启动恢复并统一保存

文件：`game/core.py`

- `Game.__init__` 在恢复音乐/音效开关后，从 `prefs.load()` 恢复两个音量。
- `_save_profile()` 写入 `master_volume` 和 `sfx_volume`，同时原样保留现有人数、名片、键位、零件等字段，避免整份覆盖时丢失数据。
- 新增双语文案 `cfg_master_volume`（总音量 / MASTER）与 `cfg_sfx_volume`（音效音量 / SFX VOLUME）。

### 3. 扩展设置行与交互

文件：`game/core.py`

统一使用以下 8 行索引：

| 索引 | 设置项 | 操作 |
|---|---|---|
| 0 | 音乐 | A/D、点击或 Enter 翻转，保持现状 |
| 1 | 音效 | A/D、点击或 Enter 翻转，保持现状 |
| 2 | 总音量 | A/D、左右键或点击左右半区，每次减/加 10% |
| 3 | 音效音量 | 同总音量 |
| 4 | 人数 | 沿用原循环调整逻辑 |
| 5 | 对手名字 | 沿用原开关逻辑 |
| 6 | 键位 | Enter/点击进入键位子页 |
| 7 | 返回 | Enter/点击关闭设置页 |

- 新增 `_adjust_volume(idx, step)`，供键盘和鼠标共用；调整后立即保存，并以 `pickup` 0.4 播放反馈，反馈声使用调整后的音量。
- 音量调整采用边界钳制，不在 0% 与 100% 间循环；音量行 Enter 不执行操作。
- 上下导航改为模 8；悬停与点击遍历改为 `range(8)`；人数、名字、键位、返回分支同步迁移到新索引。
- Esc 返回标题或暂停来源页的逻辑不变；标题与暂停继续共用同一设置页。

### 4. 紧凑排列八行并显示百分比

文件：`game/core.py`

- 仅设置页使用固定首行 `y=160`、行高 24、行距 28；8 行最后一行底部为 380，与 y=392 的提示保持间距，不修改全局 `ROW_H/ROW_PITCH`，也不沿用当前 6 行的 `_list_y0()` 居中结果。
- `_row()` 增加可选高度参数，默认仍为 `ROW_H`，其他页面行为不变；设置页命中区与实际 24px 行高一致。
- 设置文字按 `rect.h` 垂直居中。两条音量显示 `0%～100%`，总音量、音效音量及人数行均显示左右小三角。
- 保留现有选中样式、面板、遮罩和底部提示，不增加滚轮、拖动滑块或额外页面。

## Assumptions & Decisions

- 用户已明确“声音大小”为 **总音量**，不是音乐音量。
- 当前没有 BGM，因此总音量与音效音量都会缩放现有音效；音乐开关继续保留为占位，不为了本次需求新增背景音乐。
- 两个音量默认 100%，避免升级后突然变轻或变响；基础增益 0.45 不变。
- 新音量对后续播放立即生效；不重写正在播放的短音效 Channel，也不引入音乐通道管理。
- 不修改 `main.py`、伤害、HP、AI 决策、奖励、随机数使用、384 维 RL 观测或模型文件。

4. 验证设置页 8 行键盘循环、A/D、Enter、Esc、鼠标悬停和左右半区点击；人数、名字、键位与返回仍操作正确，两个音量调整后立即保存并可在重启后恢复。
