# 生命格（3 格血）+ 草地隐藏 实现计划

## 概要

两项改动，均只作用于对战模式：

1. **生命格**：每辆坦克（玩家与 3 个 AI）单命血量改为 **3 格**。被击中扣 1 格，受击后 0.5 秒无敌防连击、沿子弹方向轻微击退；3 格扣完才"阵亡"，扣 1 条命并回出生角复活（血量回满）。命数仍为 3（`VERSUS_LIVES`），即满状态到淘汰共 9 格血。HUD 右侧与坦克头顶都用格子显示当前血量。
2. **草地隐藏**：竞技场地图加入对称草地方块（`FOREST`）。规则为**单向可见**：站在草地里的坦克能看见外面的对手，而草地外的坦克看不见草地里的坦克（玩家的渲染与 AI 的 248 维观测都遵守此规则）。

**用户已确认**：血量改 3 格（不是单纯改 HUD）；草地规则"在草地里看得见对方，但对方看不见我们"；本次**暂不重训**，沿用现有 `models/dqn_tank.pth`。

#### 3.2 新增伤害入口（替代"一击即死"）

新增两个方法，并把现有 3 个击杀调用点改为走它们：

```python
def in_forest(self, tank):
    """坦克中心所在格是否为草地。"""
    c = min(int((tank.x + S.TANK_SIZE / 2) // S.TILE_SIZE), S.MAP_COLS - 1)
    r = min(int((tank.y + S.TANK_SIZE / 2) // S.TILE_SIZE), S.MAP_ROWS - 1)
    return self.grid[r][c] == S.FOREST

def _knockback(self, tank, direction, dist=S.HIT_KNOCKBACK):
    """沿 direction 击退 dist 像素；撞地形/其他坦克则放弃（不做部分位移）。"""
    dx, dy = S.DIR_VECTORS[direction]
    nx, ny = tank.x + dx * dist, tank.y + dy * dist
    rect = pygame.Rect(int(nx), int(ny), S.TANK_SIZE, S.TANK_SIZE)
    if nx < 0 or ny < 0 or nx > S.SCREEN_WIDTH - S.TANK_SIZE \
            or ny > S.TILE_SIZE * S.MAP_ROWS - S.TANK_SIZE:
        return
    if self.rect_hits_tiles(rect, (S.STEEL, S.RIVER, S.BASE)) or self._rect_hits_tank(rect, exclude=tank):
        return
    tank.x, tank.y = nx, ny
```

> `_rect_hits_tank(rect, exclude=None)`（L376-382）已支持排除自身，无需改动。

```python
def _damage_foe(self, foe, by_player, direction):
    """AI 受击：扣 1 格血。未死 -> 短无敌+击退；归零 -> 消耗 1 命，命尽淘汰，否则 1 秒后复活。"""
    foe.hp -= 1
    self.explosions.append(Explosion(foe.x + S.TANK_SIZE // 2, foe.y + S.TANK_SIZE // 2))
    self._add_flash(foe.rect)
    self.shake = max(self.shake, 4)
    self.audio.play("explosion", 0.6)
    if by_player:
        self.score += S.SCORE_KILL          # 每扣 1 格 +100 分
    if foe.hp > 0:
        foe.invincible = S.HIT_INVINCIBLE
        self._knockback(foe, direction)
        return
    # 血量归零 -> 阵亡
    foe.alive = False
    if by_player:
        self.kills += 1                     # 击杀数只统计淘汰
    foe.lives -= 1
    if foe.lives > 0:
        foe.respawn_timer = 60
```

#### 3.5 草地规则落点

- 玩家在草地 → 看得见所有 AI（渲染层实现）。
- 玩家在草地 → AI 观测里看不到玩家（`build_foe_state` 掩码实现，见第 5 节）。
- 玩家在草地外 → 看不到草地里的 AI（渲染层）；学习者的观测同样看不到草地里的 AI（对称规则）。

## 假设与决策

- 血量与命数并存：每命 3 格，掉命后回出生角满血复活（保留现有复活手感）；满状态到淘汰需 9 格伤害。
- 伤害数值统一 1 格（子弹、扇形、冲击波、疾冲）；范围技能对同一目标单次只扣 1 格。
- 计分：每扣 1 格 +100（沿用 `SCORE_KILL` 常量）；`kills` 只统计淘汰。
- 受击无敌 `HIT_INVINCIBLE=30`，与复活无敌（120 帧）独立；无敌期间子弹被吸收（沿用现有逻辑）。
- 击退只做"整段位移或完全不动"，不做部分位移，避免卡墙角。
- 草地隐藏按对称规则实现（AI 同样能借草地藏身）；玩家视角只影响渲染，AI 视角影响观测掩码。
- 本次不重训模型（用户决定）；如需最佳表现，后续可跑 `python train.py --episodes 1000`。
