# 核心战斗音效复古增强计划

## Summary

按已确认范围，只优化三类核心战斗音效：**三型号开火、普通中弹、淘汰爆炸**，保持 FC 8-bit 复古基调。通过短方波、低频音与低通噪声的分层组合提升辨识度，同时保留现有音效开关、无声卡降级、其他技能/UI/胜负音效和全部玩法规则。

不新增外部音频素材或依赖，不加入背景音乐，不改地形、道具、毒圈和菜单音效。

## Current State Analysis

- `game/audio.py:14-40` 已具备扫频、噪声和音符合成器，使用现有 NumPy 与 `pygame.sndarray`，可直接分层组合，无需新依赖。
- `game/audio.py:67-73` 目前只有 `shoot/explosion/pickup/win/lose` 五个音效；所有坦克共用射击声，中弹与淘汰共用爆炸声。
- `game/audio.py:86-96` 使用 `Sound.set_volume()` 后 `Sound.play()`；同一音效被玩家与 AI 以不同音量连续播放时，音量属于共享 Sound，可能互相影响，应改为每次播放的 Channel 音量。
- `game/core.py:1203-1225` 玩家实体弹、`game/core.py:1227-1239` 重装扇形普攻、`game/core.py:1437-1459` AI 实体弹共用 `shoot`。
- `game/core.py:1859-1895` 无论 HP 是否归零都播放 `explosion`，普通命中与淘汰缺少声音层级。
- 轻骑疾冲在 `game/core.py:1349` 使用 `shoot`，重装冲击波在 `game/core.py:1370`、毒圈淘汰在 `game/core.py:1731` 使用 `explosion`；这些不在本次范围内，旧音效必须保留。
- `game/prefs.py` 已持久化 `sfx` 开关，`main.py` 无需增加入口或配置；无音频设备时 `Audio` 当前可静默降级。

## Proposed Changes

### 1. 增加确定性的分层合成能力

文件：`game/audio.py`

- 保留 `_sweep()`、`_noise()`、`_notes()` 和 `_to_sound()` 的现有接口及 NumPy 合成路线。
- 新增一个小型 `_mix(*signals)` 辅助函数：按最长音轨补零叠加多层波形，若峰值超过 0.95 则整体等比限制到 0.95，避免单音效内部削波。
- `_noise()` 增加可选 `seed=7` 参数；每个新音轨使用明确且固定的局部种子，保持可重复测试，不消耗 Python 全局 `random`、NumPy 全局随机或游戏 `fx_rng`。
- 新音效仍在 `Audio` 初始化时一次生成并缓存，战斗播放阶段不生成波形、不创建随机对象。

### 2. 新增三型号开火与两级命中音效

文件：`game/audio.py`

在保留旧 `shoot/explosion/pickup/win/lose` 的基础上新增以下音效：

| 音效键 | 合成结构 | 听感与用途 |
|---|---|---|
| `shoot_scout` | 约 55ms 高音方波 1250→520Hz，叠 25ms 轻噪声 | 短促、轻脆，轻骑每颗实体弹触发一次，二连发自然形成双声 |
| `shoot_standard` | 约 85ms 方波 760→180Hz，叠短低频正弦和轻噪声 | 均衡、清晰，标准坦克实体弹使用 |
| `shoot_heavy` | 约 130ms 低方波 380→80Hz，叠 120→45Hz 低频与低通噪声 | 更厚、更重，重装扇形普攻使用 |
| `hit` | 约 90ms 短噪声＋高频金属方波＋快速下滑低音 | 明确但短促的普通非致命中弹反馈，不与开火声混淆 |
| `kill` | 约 320ms 低通噪声＋260→45Hz 下滑方波＋低频衰减 | 比普通中弹更长的淘汰爆燃，保留 8-bit 风格而非写实爆破 |

- 各层音量控制在现有主音量体系内，最终仍由 `_MASTER_VOLUME = 0.45` 和调用方音量缩放。
- 旧 `shoot` 继续供轻骑疾冲使用；旧 `explosion` 继续供重装冲击波和毒圈淘汰使用，不顺带重制这些事件。

### 3. 修正单次播放音量隔离

文件：`game/audio.py`

- `Audio.play()` 改为获取空闲 `pygame.mixer.Channel`，在该 Channel 上设置 `_MASTER_VOLUME * volume` 后播放 Sound。
- 不再调用共享 `Sound.set_volume()`，避免 AI 的 0.3 音量影响仍在播放的玩家 0.7 开火声。
- 没有可用通道时静默跳过，沿用 mixer 默认通道数，不额外抢占或停止其他音效。
- 保留 `enabled/sfx_on` 判断和 `pygame.error` 静默处理，无设备训练环境行为不变。

### 4. 按型号与结果接入战斗事件

文件：`game/core.py`

- 玩家 `_fire_bullet()`：根据 `self.player.tank_type` 播放对应 `shoot_scout/shoot_standard/shoot_heavy`，玩家音量仍为 0.7。
- AI `_foe_fire_bullet()`：根据 `foe.tank_type` 选择同套型号音效，AI 音量仍为 0.3。
- `_fan_fire()`：重装普攻改用 `shoot_heavy`，玩家/AI 音量仍为 0.7/0.3。
- 标准穿甲弹仍走 `_fire_bullet()`，沿用标准开火声；不新增穿甲专属音效。
- `_damage_foe()`：先按扣血后的 HP 判断，`hp > 0` 播放 `hit`（0.55），`hp <= 0` 播放 `kill`（0.75）；计分、击退、掉道具和击杀播报顺序不变。
- `_on_player_hit()`：非致命播放 `hit`（0.8），致命播放 `kill`（1.0）；失败结算仍按原逻辑播放 `lose`。
- 不修改疾冲、冲击波、毒圈、地形、道具、UI、胜利和失败的既有音效调用。

### 5. 同步现有说明

文件：`docs/GDD.md`、`docs/UI设计规范.md`

- GDD 音效段更新为三型号分层开火、短中弹与长淘汰爆炸，注明代码合成、固定局部随机种子、Channel 独立音量及无设备降级。
- UI 战场反馈表同步玩家/AI 开火、有效命中和淘汰的声音描述。
- 仅更新既有文档版本与对应条目，不新增设置项或说明文件。

## Assumptions & Decisions

- 用户已选择“仅核心三类”和“复古增强”，因此不增加砖墙/钢板、技能、无敌吸收、道具或菜单专属声音。
- 保留旧音效键是为了兼容未纳入范围的疾冲、冲击波和毒圈，不是新增兼容层。
- 不修改 `game/settings.py`、`game/prefs.py`、`main.py`、伤害、HP、射速、弹匣、碰撞、AI 决策、奖励、384 维 RL 状态或模型。
- 不添加随机音高变化，保证相同事件每次波形一致；三型号与命中结果本身提供辨识度。
- 不添加音频资源文件到项目；验证所需的临时音频/调试输出仅放在系统临时目录。

## Verification

1. 运行 `python -m compileall main.py game`，确认语法通过。
2. 在 dummy 音频设备下检查所有新旧音效可生成：波形非静音、长度符合设计、无 NaN，三型号开火及 `hit/kill` 波形互不相同；轻骑短于标准，标准短于重装，中弹短于淘汰。
3. 连续以不同音量播放同一音效，检查播放 Channel 的音量分别为 `_MASTER_VOLUME × 调用音量`，共享 Sound 不再被后一次播放改音量。
4. 用记录型假 Audio 替换真实播放，逐一验证三型号玩家/AI 开火键与音量、AI 非致命/致命、玩家非致命/致命的事件路由；同时核对 HP、分数、命中数和击退规则不变。
5. 模拟 mixer 初始化失败，确认 `Audio.enabled=False` 且 `play()` 不抛异常；dummy 环境下游戏和 RL 可正常运行。
6. 检查音效生成及播放前后的 Python/NumPy 全局随机状态不变；运行 RL `reset()/step()`，确认仍为 384 维有限数值。
7. 使用真实 Windows 音频设备依次播放三型号开火、中弹和淘汰，确认 mixer 能创建播放 Channel、无异常；再通过实际游戏入口进行一次开火/受击/淘汰冒烟检查。
