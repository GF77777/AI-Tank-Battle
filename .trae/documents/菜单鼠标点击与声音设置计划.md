# 菜单鼠标点击与声音设置计划

## 目标

1. 菜单 UI 全面支持鼠标点击（标题菜单/坦克仓库/暂停/结算/提示页/新设置页）；对局内仍用键盘。
2. 新增「设 置」功能：音乐开关（占位，当前无 BGM）+ 音效开关（立即生效），设置持久化到 prefs.json。

## 现状分析（已探明）

- **事件流**：main.py L41-56 把所有 pygame 事件传给 `Game.handle_event(event)`（core.py L228）；当前 L232 `event.type != pygame.KEYDOWN: return True` 直接忽略鼠标。**main.py 无需改动**。
- **坐标换算**：窗口 832×928 = 逻辑 416×464 × SCALE=2（settings.py L13-15）；鼠标 event.pos 为窗口坐标，**除以 SCALE 得逻辑坐标**。
- **可点击区域（逻辑坐标，静态）**：
  - 标题模式行：`_menu_button(y=188+i*32, width=240)` → Rect(88, 188+i*32, 240, 30)，i=0,1,2
  - 坦克配置行 y=322、人数配置行 y=356（Rect(88, y, 240, 30)），左右箭头是渲染时计算的动态位置
  - 暂停行：`_menu_button(y=224+i*36, width=200)` → Rect(108, 224+i*36, 200, 30)
  - 仓库箭头：cy=222，左 (w//2-100..w//2-88)、右 (w//2+88..w//2+100)，±8px
  - 结算/提示页：无按钮，整屏点击 = Enter 行为
- **音频**：audio.py `Audio` 仅音效池（shoot/explosion/pickup/win/lose），`play()` 由 `self.enabled` 门控；**无 BGM、无开关**。
- **状态机**：STATE_START（+garage 布尔子视图）/PLAYING/PAUSED/WIN/LOSE；菜单常量 ROW_TANK_CONFIG=3、ROW_NUM_CONFIG=4、ROW_COUNT=5（core.py L23-26）。
- 训练链（env/train）不经过这些 UI，改动零影响；Audio 在 headless 下 enabled=False 自动降级。

## 改动方案

### 1. game/prefs.py（新建，~25 行）

`load() -> dict` / `save(dict)`：项目根 `prefs.json`，默认 `{"music": true, "sfx": true}`；读失败/缺键回默认。供设置持久化。

### 2. game/audio.py — 开关接口

- `__init__` 末尾加 `self.music_on = True; self.sfx_on = True`（由 Game 用 prefs 覆盖）。
- `play()` 首行门控改为 `if not self.enabled or not self.sfx_on: return`。
- 新增 `set_sfx(on)` / `set_music(on)`：置位即可；`set_music` 加注释「占位：当前无 BGM，待加入后在此 start/stop」。

### 3. game/settings.py — 常量

- `PREFS_DEFAULT = {"music": True, "sfx": True}`（prefs.py 也可用，二选一放 settings）。
- 无其他改动（布局坐标写进 core.py 常量）。

### 4. game/core.py — 主体改动

**常量区（L23-26）**：
- `ROW_SETTINGS = 5`、`ROW_COUNT = 6`
- 布局常量（渲染与命中共用）：`MENU_X, MENU_W = 88, 240`；`MODE_Y0, ROW_H = 188, 30`；行距 32；`ROW_TANK_Y=322, ROW_NUM_Y=356, ROW_SET_Y=388`；底部分割线 394→424、hints 404/420→432/444（避开新设置行 388..418）。
- 设置页行：`SET_ROWS = ("设置-音乐", "设置-音效", "设置-返回")`，y = 208 + i*44（h30）。

**`__init__`（L123-143）**：
- `self.settings_view = False`、`self.settings_index = 0`、`self.settings_from = None`（"title"/"pause"）
- `self._hits = {}`（渲染帧写入的动态命中区：配置行箭头/仓库箭头/仓库选用区）
- 载入 prefs：`p = prefs.load()` → `self.audio.set_music(p["music"]); self.audio.set_sfx(p["sfx"])`

**`handle_event`（L228）**：在 KEYDOWN 判定之前插入 MOUSEBUTTONDOWN（button==1）：
- 坐标：`mx, my = event.pos[0] // S.SCALE, event.pos[1] // S.SCALE`
- STATE_START + settings_view：点行 i → `settings_index=i`，行 0/1 翻转并 `prefs.save`，行 2 关闭
- STATE_START + garage：`self._hits["garage_left/right/select"]` 命中 → 翻页/选用（同 ←/→/Enter）
- STATE_START + notice：任意点击 → `start_notice=None`
- STATE_START 根视图：模式行命中 → `mode_index=i` + `_confirm()`（单击即触发，含对战/曲线/仓库/设置）；坦克/人数/设置行命中左半 → step -1、右半 → step +1（等价 A/D，音效 pickup 照播）
- STATE_PAUSED + settings_view：同标题设置页逻辑
- STATE_PAUSED：暂停行命中 → `pause_index=i` + `_confirm()`
- STATE_WIN/LOSE：任意点击 → `_start_versus()`
- 其余点击忽略；MOUSEMOTION 不处理

**键盘分支适配**：
- ESC 分支（L237）最前加：`if self.settings_view: self.settings_view=False; return True`
- ←/→/A/D、↑/↓ 分支最前加 settings_view 拦截：↑/↓ 移 settings_index(0..2)，←/→/A/D 翻转行 0/1（行 2 无操作）
- `_confirm` 的 STATE_START 分支最前加 settings_view 拦截：行 0/1 翻转+保存，行 2 关闭

**`_confirm` 暂停分支（L304）**：`pause_index == 3` → `settings_view=True; settings_from="pause"`；pause_index 循环范围 3→4（L276 `% 3` 改 `% 4`）。

**标题根视图 `_confirm`（L293-303）**：加 `elif self.mode_index == ROW_SETTINGS: self.settings_view = True; self.settings_from = "title"`。

**渲染**：
- `_render_start`：garage 判断后加 `if self.settings_view: self._render_settings(screen); return`
- `_render_start` 根视图：设置行用 `_menu_button(T("mode_settings"), ROW_SET_Y, mode_index == ROW_SETTINGS)`；分割线/hints 用新常量
- 新增 `_render_settings(screen)`：标题「设 置」y=152；三行（音乐/音效/返回）标签居左、值（开/关 或 空）居右，样式复用配置行（选中白底条+黄竖条）；底部 hint「点击或 A/D 切换 · Esc 返回」
- `_render_config_tank` / `_render_config_count` / `_render_garage`：渲染时把箭头与选用区 Rect 写入 `self._hits`（即时模式 GUI，零漂移）
- `_render_pause`：菜单项加 `"settings"`（4 项，y=224+i*36 → 224/260/296/332，hint 362→372，面板高 260 不变够放）；新增文案 `"mode_settings": ("设 置", "SETTINGS")`、`"cfg_music": ("音 乐", "MUSIC")`、`"cfg_sfx": ("音 效", "SFX")`、`"cfg_back": ("返 回", "BACK")`、`"set_on": ("开", "ON")`、`"set_off": ("关", "OFF")`、`"hint_settings"`

**翻转动作收敛为小方法** `_toggle_setting(idx)`：idx0→music、idx1→sfx，翻转 `audio.set_xxx(not cur)` + `prefs.save` + `audio.play("pickup", 0.5)`（音效行关闭后此声自然不响）。

### 5. README.md — 一行级同步

按键表加「鼠标：点击菜单/按钮」；功能列表加「设置：音乐/音效开关（持久化 prefs.json）」。

## 决策记录

- 鼠标仅菜单 UI（用户确认），对局内操作不变
- 音乐开关为占位（用户确认）：翻转+持久化生效，但当前无 BGM 可听；接口预留 `Audio.set_music`
- 模式行单击 = 选中并立即确认（一步直达）；配置行左右半区点击 = A/D 等价
- 设置入口两处：标题第 6 行 + 暂停第 4 项（共用同一设置视图，`settings_from` 记录返回目标）
- 不做鼠标悬停高亮（MOUSEMOTION），保持改动最小
- headless/训练不受影响：Audio enabled=False 时全部 no-op
