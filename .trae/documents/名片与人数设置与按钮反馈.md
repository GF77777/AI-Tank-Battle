## Proposed Changes

### 1. game/prefs.py — 泛化持久化

- `_DEFAULT = {"music": True, "sfx": True, "players": 4, "name": "玩家", "avatar": ""}`
- `load()`：按键存在性+类型匹配（`isinstance(data[k], type(default))`）合并；bool 键仍 bool 化。
- `save(prefs)`：直接 `json.dump`（不再强制 bool）。

### 2. game/settings.py — 人数上限

- `NUM_COMBATANTS_MAX = 10`；删除 `SPAWNS_BY_COUNT`（被生成算法取代）。

### 3. game/level.py — 新增 `generate_spawns(grid, n)`

- 候选 = 全部 EMPTY 格，shuffle 后贪心选取：与已选点 Chebyshev 距离 ≥3；选不足 n 时依次降距 2、1 重试（17x17 图 10 人 ≥3 足够，降为兜底）。
- 返回 `[(col, row), ...]` 长度 n；玩家恒取 [0]（调用方约定不变）。

### 4. game/avatars.py（新文件）— 头像/名字池

```python
"""玩家/AI 名片池：扫描 assets/avatars/*.png，文件名（去扩展名）即名字。"""
```
- `load()`：懒加载扫描（png/jpg），`pygame.image.load`；display 已初始化则 convert_alpha（仿 sprites._load_skin 兜底）。缓存原图。
- `pool()` → [(name, surface)]；`assign(n, exclude=())` 随机不重复抽 n 个，池不足允许重复；空池返回 []。
- `scaled(surface, size)`：缩放缓存 dict。
- `by_filename(stem)`：按文件名取（玩家持久化头像用）。

### 5. game/env.py — 训练局隔离

- L143：`S.NUM_COMBATANTS_MAX` → `4`（注释：训练恒 4 人局，与玩家侧 2-10 可选隔离）。

### 6. game/core.py — Game 状态与持久化

- `__init__`：`p = prefs.load()` 增读 `players/name/avatar`；`self.num_combatants = p["players"]`（钳 2-10）；`self.player_name = p["name"]`；`self.player_avatar = avatars.by_filename(p["avatar"]) or 随机一个（并回写 avatar 文件名待 save）`；`self.profile_view = False`、`self.profile_editing = ""`（改名缓冲区）。

## Assumptions & Decisions

- 素材约定：`assets/avatars/疾风.png` → 名字"疾风"；用户自行投喂；池空/目录缺失时 AI 回退 A/B/C 字母、无头像，游戏照常可玩。
- 玩家头像也从池中分配（启动随机一个并持久化到 prefs.avatar）；玩家改名持久化 prefs.name。
- 出生位随机化同时作用于训练局（域随机化，状态维度不变 382，无需重训结构）。
- roam 靶子保留 T1-T4（不分配名字头像）。
- 击杀播报/结算的头像通过 `self._avatar_by_tag` 反查，避免改 kill_feed 元组结构以外的接口。
- 设置页人数调整即时生效于下一局（开局 _reset_battle 读取）。
- hover/按压在无头环境无法模拟，靠截图目检常态 + 实机确认。
