# 对战规则重构：1 命制 + 道具系统 + 多地图随机

## Summary

按用户决策重构对战核心规则：
1. **1 命制**：每方只有 1 条命（3 格血），血尽即淘汰，删除复活机制；
2. **道具系统**：加血 / 火力 / 护盾 / 地雷四种，定时随机刷 + 击杀掉落双通道；
3. **多地图**：3 张手工设计的四向对称预设图，每局随机抽取；
4. **RL 奖励同步重构**：淘汰 +500 / 被淘汰 -500 / 每步 -1（删除原 VS_R_WIN/VS_R_LOSE 与 VS_R_KILL=100 的小额击杀奖）。

**代价**：状态向量 248→260 维（新增道具槽），旧模型 `dqn_tank.pth` 不兼容，归档到 `models/legacy/` 后需重训。

```python
class Item:
    """地面道具：kind ∈ heal/fire/shield/mine；ttl 到 0 消失。"""
    SIZE = 16
    def __init__(self, col, row, kind, ttl):
        self.x = col * S.TILE_SIZE + (S.TILE_SIZE - self.SIZE) // 2
        self.y = row * S.TILE_SIZE + (S.TILE_SIZE - self.SIZE) // 2
        self.kind = kind
        self.ttl = ttl
        self.alive = True
    @property
    def rect(self):
        return pygame.Rect(self.x, self.y, self.SIZE, self.SIZE)
```

**道具系统**（新增方法）：
- `_update_items()`：update() 中调用。① `item_timer` 倒数到 0 → 重置 600 → 若定时道具 < `ITEM_MAX_TIMED` 且总数 < `MAX_ITEMS` → 随机空格（`EMPTY` 且无坦克/道具重叠）刷一个（类型 `random.choice(ITEM_TYPES)`，`source="timed"`）；② 所有 item `ttl -= 1`，到 0 移除；③ 遍历存活坦克 rect 碰撞：`mine` → 受伤处理（玩家走 `_on_player_hit(None)`、AI 走 `_damage_foe(foe, by_player=False, direction=None)`），无敌/护盾中不触发；其余三种 → `_apply_item(tank, kind)` + `audio.play("pickup", 0.5)`，item 移除。
- `_drop_item(foe)`：击杀掉落。若已有 `source="drop"` 的道具则先删旧的；在 foe 死亡格生成 `random.choice(ITEM_DROP_TYPES)`。
- `_apply_item(tank, kind)`：`heal` → `hp=min(hp+1, max_hp)`；`fire` → `fire_stacks=min(+1, FIRE_MAX_STACKS)`，`fire_cooldown_max=max(int(base*0.7**stacks), FIRE_COOLDOWN_MIN)`（base：玩家用 `base_fire_cooldown`，AI 用 `2*S.PLAYER_FIRE_COOLDOWN`）；`shield` → `invincible=max(invincible, SHIELD_FRAMES)`。
- 渲染：`_render_field` 在地形之后、坦克之前画道具；`ttl < ITEM_BLINK_TTL` 时按 `(frame//10)%2` 闪烁。

## Assumptions & Decisions

| 决策 | 理由 |
|---|---|
| 地雷是地面陷阱（踩中扣 1 格），不是玩家可放置物 | 用户选项原文即"踩中扣 1 格"；实现量小且与 FFA 兼容 |
| 护盾复用 `invincible` 字段 | 与出生保护同一机制，零新碰撞分支；护盾期踩地雷不触发（合理协同） |
| 道具进 RL 状态且 AI 能捡 | 用户选项明确；否则训练/对战分布不一致 |
| 击杀掉落池不含地雷 | 避免"击杀瞬间死亡点埋雷"的挫败感；定时池含地雷保持四种都在场 |
| 新掉落顶掉旧掉落（上限 1） | 防止满屏道具稀释战斗节奏 |
| 旧模型归档而非删除 | 保留回溯可能；同时避免 `main.py` 误加载 248 维旧模型崩溃 |
| 出生保护沿用 `RESPAWN_INVINCIBLE=120` | 1 命制下开局 2s 无敌防开场秒死，名称不改减少波及面 |
| 地图只从预设池随机、保持四向对称 | FFA 公平性 + RL 泛化（域随机化），无需改 169 维地图编码 |
