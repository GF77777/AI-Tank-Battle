# 首页地图亮色战术蓝图优化

## 概要

将首页地图预览从“黑底稀疏色块”改为 **B：亮色战术蓝图**。保留现有深色首页、黄色焦点色、卡片位置和键盘操作，不引入真实地形贴图，不调整对局地图、战争迷雾或玩法逻辑。

## 现状分析

- [core.py](file:///c:/Users/CGF/Desktop/AI坦克大战/game/core.py#L2333-L2351) 的首页地图卡为 `200×152`，箭头仅 `24×24`，地图名始终为黄色，选中反馈主要只有一圈细黄框。
- [core.py](file:///c:/Users/CGF/Desktop/AI坦克大战/game/core.py#L2369-L2387) 只绘制非空地形，空地透明后露出近乎黑色的面板，导致预览整体偏黑、地形分布不直观。
- [core.py](file:///c:/Users/CGF/Desktop/AI坦克大战/game/core.py#L855-L865) 中箭头可以切换地图，但点击预览卡只会聚焦，鼠标操作感较弱。
- 地图数据来自 [level.py](file:///c:/Users/CGF/Desktop/AI坦克大战/game/level.py#L87-L93) 的 3 张 `17×17` 模板；现有共享按钮三态由 `_btn_face()` 提供，可直接复用。

## 修改方案

### 1. 将缩略图改为浅色网格蓝图

修改 [core.py](file:///c:/Users/CGF/Desktop/AI坦克大战/game/core.py#L2369-L2387) 的 `_render_map_thumb()`：

- 保持 `CARD_TANK = (108, 60, 200, 152)` 不变，在卡片内绘制 `(card.x+10, card.y+10, 180, 108)` 的浅暖色预览底板。
- 底板使用局部颜色常量：背景 `(235, 232, 220)`、网格 `(210, 205, 190)`、边框 `(126, 122, 112)`；不修改全局 UI 配色。
- 保留 `17×17` 模板和每格 `6px` 的尺寸，网格区域仍为 `102×102`，水平居中，顶部位于 `card.y+13`；空地也显示浅色底和细网格。
- 地形继续使用原模板字符映射，但替换为高辨识度的明亮几何色块：
  - 砖墙：暖橙 `(224, 124, 72)`。
  - 钢板：蓝灰 `(113, 128, 145)`，加浅色内高光。
  - 河流：亮蓝 `(86, 164, 224)`，加简短水纹线。
  - 森林：草绿 `(104, 178, 102)`，用圆形或小型树冠几何形区别普通方块。
- 随机地图使用同样的浅色网格底，中央显示深灰色 `?`，不再退回黑色空卡。
- 仅修改预览渲染，不读取地板 PNG，不改变真实地图材质。

### 2. 强化焦点与箭头反馈

修改 [core.py](file:///c:/Users/CGF/Desktop/AI坦克大战/game/core.py#L2333-L2351) 的 `_render_start()`：

- 保留深色外卡和现有 `_panel()` 风格；键盘选中或鼠标悬停地图区域时，外框改为 `2px` 黄色边框，未聚焦时维持普通边框。
- 地图名只在当前聚焦时使用黄色，未聚焦改为白色，避免始终黄色造成状态不清。
- 左右箭头保持当前中心位置，命中区和按钮由 `24×24` 放大到 `28×28`；继续复用 `_btn_face()` 的悬停、按下三态。
- 箭头三角适当放大：默认白色，地图区域聚焦或箭头悬停时为黄色；按下仍沿用现有方向位移反馈。
- `_hits` 键名和首页其他按钮布局保持不变。

### 3. 让预览卡可直接切换

修改 [core.py](file:///c:/Users/CGF/Desktop/AI坦克大战/game/core.py#L831-L865) 的 `_on_click()`：

- 左右箭头仍分别执行 `-1/+1`，并保持优先于卡片点击处理。
- 点击 `cfg_map_card` 左半区时切换上一张，点击右半区时切换下一张；点击前统一设置 `mode_index = ROW_MAP_CONFIG`。
- 复用 `_adjust_config_row()`，继续在“随机 + 3 张地图”之间循环并播放现有音效，不新增切换规则。
- 键盘 `A/D`、鼠标移动接管焦点、`W/S` 离开地图行等行为不变。

## 明确不改

- 不修改 [settings.py](file:///c:/Users/CGF/Desktop/AI坦克大战/game/settings.py) 的全局颜色、分辨率、视野或相机参数。
- 不修改 [level.py](file:///c:/Users/CGF/Desktop/AI坦克大战/game/level.py) 的地图模板、碰撞和出生点。
- 不修改 [sprites.py](file:///c:/Users/CGF/Desktop/AI坦克大战/game/sprites.py)、对局渲染、排位迷雾、小地图、AI 或 RL 状态。
- 不采用四格直选，不新增图片资源或设置项。

## 验证

1. 对 `game/core.py` 执行 `py_compile` 语法检查。
2. 使用无头 SDL 渲染首页，逐一检查随机及三张地图：浅底网格完整、地形可区分、随机 `?` 居中、地图名与箭头不重叠。
3. 检查键盘焦点和鼠标悬停均只出现一个黄色高亮项；离开地图区域后普通边框和白色地图名恢复。
4. 验证左右箭头、预览卡左右半区的切换方向与循环顺序一致，均只切换一次并复用现有音效。
5. 回归 `W/S/A/D`、Enter、首页五个按钮和名片点击区域，确认命中区没有串扰；从首页开局后地图索引仍按原规则加载。
