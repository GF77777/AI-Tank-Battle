# UI 重排与视觉统一（复古像素风）

## 1. 目标
- 视觉方向：**保留现有深色底 + 黄/红配色 + 像素字体**，只做规整排版，不做换风格。
- 范围：全部页面（主菜单、特殊模式、名片、设置、键位、坦克仓库、暂停、结算、对局 HUD/播报）。
- 三个统一：
  1. 统一**页面骨架**：面板区 → 标题 → 内容行区 → 底部提示区。
  2. 统一**五个视觉规格**：面板、标题、行高、行距、提示字号。
  3. 统一**命中区来源**：鼠标热区全部由渲染时写入 `_hits`，删除 `_on_click` 里重复的坐标计算，改布局不会再点不准。

## 2. 现状问题（基于 core.py 实际代码）

| 设置 | 面板 `(24,140,368,320)`，`SET_Y0=208` 行距 44 | 与其它子页面板高度/起始 y 全不同，切换页面时面板跳动 |

## 3. 设计规范（唯一来源，写在 core.py 顶部常量区）
```python
# ---- 页面骨架（逻辑像素）----
PANEL_X, PANEL_Y, PANEL_W, PANEL_H = 24, 104, 368, 312   # 统一子页面板：104..416
TITLE_Y   = PANEL_Y + 12      # 116，20px 黄字居中
TITLE_LINE_Y = PANEL_Y + 44   # 148，标题下分隔线（40..376）
LIST_Y0   = PANEL_Y + 56      # 160，首个内容行
ROW_H     = 30                # 行高（可点区域）
ROW_PITCH = 36                # 行距
HINT_Y    = PANEL_Y + 288     # 392，底部提示
MENU_X, MENU_W = 88, 240      # 列表行 x/宽（保持现有值）

# ---- 主菜单 ----
CARD_TANK = (108, 60, 200, 152)   # 卡片下移到 60，底部 212
MODE_Y0   = 226                   # 按钮列首行（226 + 4×34 = 362）
MODE_PITCH = 34
FOOTER_LINE_Y = 404               # 底部线
FOOTER_HINT_Y = 414
FOOTER_AI_Y   = 434

# ---- 暂停 ----
PAUSE_PANEL = (88, 132, 240, 248)   # 与按钮同宽，居中
PAUSE_TITLE_Y = 146
PAUSE_Y0 = 194                       # 行距 38，4 行到 308
PAUSE_HINT_Y = 330

# ---- 结算 ----
END_CARD_A = (24, 92, 368, 92)      # 战绩横条
END_CARD_B = (24, 192, 368, 176)    # 排名表
END_BTN_Y  = 380
END_BTN_W, END_BTN_H, END_BTN_GAP = 150, 32, 16
```
新增配色（settings.py）：`PANEL_BG=(10,10,14)`、`PANEL_BORDER=(72,72,84)`、`ROW_SEL=(255,255,255,14)`、`HL_YELLOW` 沿用 `YELLOW`。

排版细则：
- 面板：`_panel` 统一 `alpha=200` + 1px `PANEL_BORDER`；标题下画 1px `DARK_GRAY` 分隔线（x=PV+16..PV+W-16）。
- 行：高 30，`ROW_PITCH=36`；选中 = 白 14 alpha 底条 + 左侧 3px 黄竖条 + 黄字；悬停 = 白 8 alpha 底条 + 白字；按下 = 白 24 alpha + 文字下移 1px。
- 行数不足时**垂直居中**：`y0 = LIST_Y0 + max(0, ((PANEL_H - 68 - 24) - (n*ROW_H + (n-1)*(ROW_PITCH-ROW_H))) // 2)`，用 `_list_y0(n)` 统一计算（特殊 2 行、名片/设置 5 行、键位 6 行）。

## 4. 逐文件改动

### 4.1 `game/settings.py`
- 新增颜色常量：`PANEL_BG`、`PANEL_BORDER`、`ROW_SEL`。
- 其余常量（TILE/SCREEN/键位等）不动。

### 4.2 `game/core.py`

**A. 常量区（替换现有 MENU_*/MODE_Y0/CARD_TANK/SET_Y0/KEYBIND_Y0/PAUSE_*）**
- 按第 3 节写入新常量；`SET_Y0`、`KEYBIND_Y0` 删除（改由 `_list_y0(n)` 统一生成）。
- 新增 `PROFILE_BOX = (SCREEN_WIDTH//2 - 110, 256, 220, 32)`，名片输入框与 `ime.enable(...)` 共用（`_on_click` 里那处硬编码同步替换）。

**B. 新增绘制助手（放在 `_panel` 附近）**
- `_panel(screen, rect, alpha=200)`：改统一描边色。
- `_page_title(screen, key, y=TITLE_Y)`：20px 黄字居中 + 标题下分隔线。
- `_hint(screen, key, y=HINT_Y)`：12px 灰字居中。
- `_list_y0(n)`：按第 3 节公式算垂直居中的首行 y。
- `_row(screen, y, selected, hoverable=True)`：画底条/竖条，返回 `pygame.Rect`（供 `_hits`）。
- `_menu_button(screen, text, y, selected, width=MENU_W, key=None)`：改用 `_row`，统一三态样式；可选写入 `_hits["btn_"+key]`。
- `_card_button(screen, rect, title_key, desc_key, selected, hit_key)`：特殊模式用卡片（标题 16px + 描述 12px 灰 + 右侧三角），三态与 `_menu_button` 一致，并写 `_hits[hit_key]`。

**C. 主菜单 `_render_start`**
- 顶栏：头像 20px @ (12,12)，名字 18px @ (38,14)，底部分隔线 y=44 不变；`_hits["profile"]` 按实际宽高写。
- 卡片：`CARD_TANK` 新值；缩略图 `_render_map_thumb` 以卡片内边距 12 重算（随机 "?" 居中）；左右三角与 `cfg_map_*` 命中沿用。
- 按钮列：`MODE_Y0=226`、`MODE_PITCH=34`、宽 240；5 项写入 `_hits["btn_pure"/"btn_special"/"btn_curve"/"btn_garage"/"btn_settings"]`。
- 底部：线 y=404（x=88..328），提示 414，AI 提示 434；三行间距 ≥18。

**D. 特殊模式 `_render_special`**
- 统一面板 + `_page_title(mode_special)`。
- 两张卡片：`(48, 168, 320, 64)` 与 `(48, 240, 320, 64)`；标题左对齐 x+14，描述 x+14 第二行；选中时黄边 + 左侧竖条；命中 `_hits["sp_0"]/_hits["sp_1"]`。
- 底部 `_hint(hint_special)`。

**E. 名片 `_render_profile`**
- 统一面板 + 标题。
- 头像 56px 居中 y=176，箭头各距 22px，命中 `profile_av_left/right/av`（保留现有 key）。
- 计数 12px y=238。
- 输入框使用 `PROFILE_BOX`（高 32），文字垂直居中；组合态照旧隐藏提示。
- 提示 y=HINT_Y（316 改 392，与其它页一致）。

**F. 设置 `_render_settings`**
- 统一面板 + 标题；5 行 `_list_y0(5)` 起，`ROW_PITCH`；人数行三角、开关值右对齐（右内边距 16）。
- 底部 `_hint(hint_settings)`。
- `_settings_row_at` 改为读 `_hits["set_0".."set_4"]`（渲染时写入），删除坐标推算。

**G. 键位 `_render_keybind`**
- 统一面板 + 标题；6 行 `_list_y0(6)` 起；右侧键名用 `pygame.key.name(...).upper()`；等待态显示 `keybind_wait`。
- `_keybind_row_at` 改为读 `_hits["kb_0".."kb_5"]`。
- 底部 `_hint(hint_keybind)`。

**H. 坦克仓库 `_render_garage`**
- 新增统一面板 + 标题；大图 84px y=156；翻页三角 y=198；名称 y=248；参数 y=276；描述 y=296；页码 y=320；hint y=HINT_Y。
- 命中 `garage_left/right/select` 按新坐标写。

**I. 暂停 `_render_pause`**
- 面板 `PAUSE_PANEL`；标题 26px y=PAUSE_TITLE_Y；4 行宽 200（面板内 20 边距）y=194 行距 38；hint 330。
- `_on_click` 的暂停行改为读 `_hits["pause_0..3"]`；`PAUSE_X/PAUSE_W/PAUSE_Y0` 常量删除或改为由面板派生。

**J. 结算 `_render_end`**
- 上横条 `END_CARD_A`：左侧胜负 24px；右侧"分数 / 击杀 / 用时"三项等距一行（x 分别在 25%/50%/75%），不再竖排。
- 排名卡 `END_CARD_B`：标题 `end_rank` 18px；表头行（`#  名字  状态`）12px 灰；数据行从 y+44 起，行高 `min(24, 可用高/人数)`，最多 10 行不换行高下限 16；小头像 14px 与名字间距 6；状态右对齐。
- 底部两按钮：真实命中 `_hits["end_again"]` / `_hits["end_back"]`，点击分别 `_confirm()` / 返回标题（与 Enter/Esc 等价）。

**K. `_on_click` 统一改造**
- 删除对 `216/268`、`MODE_Y0 + i*32`、`PAUSE_Y0 + i*36`、`SET_Y0`、`KEYBIND_Y0` 的坐标推算，全部改为 `_hits.get(...)` 命中；渲染与交互共用同一份矩形。
- 结算分支：先判断两个按钮命中，未命中时保持原"任意点击重开"还是改为无操作 —— **决策：仅按钮可点**（避免误触），Enter/Esc 保留。

**L. 对局 HUD**
- `_render_hud`：左侧"剩余 N"保持；右侧在 `battle_mode == "versus"` 时显示"安全区 Xs"（红字，右对齐，右边距 10），`ZONE MAX` 同位置。
- `_render_zone_card` 删除调用与函数（信息迁入顶栏，减少战场遮挡）。
- 公告/击杀播报：右边距统一 10，背景统一 `(0,0,0,170)` + 1px 边；最多 2 条公告 + 3 条播报，纵向间距 6。
- 技能圆环：中心改为 `(W-36, H-36)`，半径 16 不变，标签在环中心。

## 5. 假设与决策
- 不改字体文件、不改主色（黄 #F0C83C / 红 #DC3228 / 绿 #50C850）；不新增图片素材。
- 交互逻辑（键盘导航 A/D/W/S/Enter/Esc、改键、头像切换、中文输入）全部不变，只改坐标与命中来源。
- 结算页双按钮改为真实命中；其余"点击即确认"的行为保持不变。
- 所有新坐标写在常量区，渲染与 `_on_click` 共用；动态命中一律写 `_hits`。

3. **功能回归**：10 人局开一局，确认 HUD 剩余数、安全区倒计时、播报/头像、技能环位置；暂停/结算进出正常。
4. **中文输入**：名片页输入框位置变更后，候选窗仍贴在输入框下方（`ime.enable(PROFILE_BOX)` 同一常量）。
