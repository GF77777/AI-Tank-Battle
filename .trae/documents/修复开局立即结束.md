# 修复"一进游戏立即结束"计划

## 1. 概要（Summary）

**根因**：玩家出生点 `(4,12)` 与基地 `(6,12)` 在同一行紧邻，中间只隔一块砖 `(5,12)`。玩家开局按"→/D"时，即使被砖墙挡住，坦克朝向也已经转为右；再按空格射击，第一发打掉砖墙、第二发直接命中自家基地 → 触发 `_end(False)`，游戏在 2 秒内结束。上一轮 300 帧模拟已重现该现象（用 3 秒、分数 0、LIFE 3，属基地被毁而非玩家阵亡）。

**修复（用户确认"两者都做"）**：

1. **禁止友军伤害**：玩家自己的子弹命中基地只消失，不再摧毁基地；敌方子弹仍可摧毁基地（保留正常失败路径）。
2. **挪开出生点**：玩家出生/复活点由 `(4,12)` 改为 `(2,12)`，离基地拉开到 4 格。

游戏逻辑、状态向量维度、奖励函数均不变，无需重训模型。

## 3. 变更内容（Proposed Changes）

### 3.1 [settings.py](file:///c:/Users/CJP/Desktop/AI坦克大战/game/settings.py) — 出生点左移

将

```python
PLAYER_SPAWN = (4, 12)
```

改为

```python
PLAYER_SPAWN = (2, 12)   # 左侧空地，远离基地（原 (4,12) 与基地仅隔一块砖，开局容易误射基地）
```

* `(2,12)` 在关卡中为空地（第 12 行 `".....BEB....."` 的 col 2 为 `.`）；
* 该点左可到 col 0、上可沿 col 0 通道走满全图，不会开局被困；
* `_on_player_hit()` 复活逻辑自动沿用新出生点，无需改 `core.py`。

### 3.2 [core.py](file:///c:/Users/CJP/Desktop/AI坦克大战/game/core.py) — 基地只吃敌方子弹

把 `_bullet_vs_tiles()` 里基地分支改为：

```python
elif tile == S.BASE:
    if self.base_alive:
        hit = True                      # 子弹被基地吸收
        if not bullet.from_player:      # 只有敌方子弹能摧毁基地
            self.base_alive = False
            self._end(False)
```

行为说明：

* 玩家子弹打在基地上：子弹消失，基地安然无恙（不再有"误杀自己"的瞬间失败）；
* 敌方子弹打在基地上：与原来完全一致，基地被毁 → 立即失败结算；
* 基地被毁后再有子弹经过该格：仍按原行为不阻挡（保持现有语义，不改动）。

## 4. 关键假设与决策（Assumptions & Decisions）

1. 用户选择"两者都做"= 友军子弹不再摧毁基地 + 出生点左移到 `(2,12)`。
2. 敌方子弹摧毁基地仍是正常失败条件，必须保留（验证时会专门回归该路径）。
3. 不改关卡砖墙布局，保持 FC 经典手感；基地仍可被敌人从侧面/打穿砖墙后摧毁，难度不变。
4. 出生点左移不影响敌人出生点与刷怪逻辑，也不改变 AI 观测维度与训练链路。
5. 旧的已训练模型无需重训：输入维度、动作空间、奖励定义都没变，只是"友军误射"不再导致 -500。
