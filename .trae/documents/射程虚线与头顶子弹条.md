# 平A射程虚线 + 头顶子弹条

## Summary
两处玩家可视化增强，只改 `game/core.py`：
1. 玩家坦克**常驻**显示平A射程虚线（单发/二连发=直线；重装=扇形）。
2. 玩家坦克**头顶血条正下方**加一排子弹格（余弹黄/已耗暗灰，换弹中逐格填充）。

## Current State（已探索确认）
- 战场渲染入口：`_render_field`（core.py:1371），逻辑分辨率 416x464，`oy=HUD_HEIGHT` 为战场 y 偏移。
- 头顶血条：内部函数 `draw_hp`（core.py:1392-1398），`x0=int(tank.x)+1`、`y0=oy+int(tank.y)-6`，每格 8x3、间距 1、总宽 26px。
- 玩家坦克绘制：core.py:1456-1460（blit 后紧跟 `draw_hp(self.player, S.GREEN)`）。
- 射程参数（entities.py:66-93 + settings.py:66-85）：
  - scout(burst)：`bullet_frames=14` → 14×5px=**70px**
  - standard(single)：`bullet_frames=19` → **95px**
  - heavy(fan)：无实体弹，`fan_radius=60`、`fan_half_angle=30` → **扇形**
  - `S.BULLET_SPEED=5`、`S.DIR_VECTORS`、`S.TANK_SIZE=21`
- 半透明绘制套路参考：`_render_fan_flash`（core.py:1522-1536，全屏 SRCALPHA surface 再 blit）。
- 迷雾在 core.py:1496-1502 之后罩下；射程最长 95px < 视野半径 144px，画在迷雾前不会被遮。
- HUD 右上角已有弹匣点（core.py:1352-1363），保留不动。

## Proposed Changes

### 1. `game/core.py` 新增 `_render_range_hint(self, screen, oy)`
- 调用位置：`_render_field` 中 `draw_hp(self.player, S.GREEN)`（core.py:1460）之后；仅 `self.player.alive` 时执行。
- 起点 = 炮口：`(x + TANK_SIZE/2 + dx*TANK_SIZE/2, oy + y + TANK_SIZE/2 + dy*TANK_SIZE/2)`。
- 按 `self.player.fire_mode`：
  - `single` / `burst`：沿朝向画 1px 虚线，长度 `bullet_frames * S.BULLET_SPEED`，端点裁剪到战场矩形 `(0, oy, MAP_COLS*TILE_SIZE, MAP_ROWS*TILE_SIZE)`。虚线节奏：4px 实 + 3px 空。
  - `fan`：画扇形轮廓——两条虚线直边（中心角 ±fan_half_angle，长 fan_radius）+ 半径处虚线弧（按角度步进采样，每段小弧线用短直线近似）。
- 颜色：半透明白 `(255, 255, 255, 160)`，画在全屏 SRCALPHA surface 上再 `screen.blit(surf, (0, 0))`（同 `_render_fan_flash` 套路）。

### 2. `game/core.py` 新增头顶子弹格
- 在 core.py:1460 `draw_hp(self.player, S.GREEN)` 之后调用新内部逻辑（可直接跟在 range hint 同一个代码块里，或抽小函数 `_draw_mag_pips(screen, oy, tank)`）。
- 位置：血条正下方 `x0=int(tank.x)+1`（与血条对齐），`y=oy+int(tank.y)-2`，每格 5x2、间距 1（mag_size≤4 → 总宽 23px ≤ 血条 26px）。
- 状态：
  - 正常：`i < tank.mag` 黄色 `S.YELLOW`，否则 `S.DARK_GRAY`。
  - 换弹中（`reload_timer>0`）：`ratio = 1 - reload_timer/reload_frames`，前 `int(ratio*mag_size)` 格黄，其余暗灰（与 HUD 弹匣点逻辑一致）。
- 只画玩家，不给 AI（避免画面杂乱）。

## Assumptions & Decisions
- 只显示玩家自己的射程与子弹条；AI 对手不加。
- 虚线为固定射程长度，不预判墙体遮挡，仅裁剪到地图边界。
- 只画平A射程；蓄力技（穿甲弹/疾冲/冲击波）不画。
- HUD 右上角已有的弹匣点保留不变。

## Verification
1. `python main.py` 开局，车库分别选三款坦克：
   - scout：炮口前方 70px 虚线，随朝向转动。
   - standard：95px 虚线。
   - heavy：60px、30° 扇形虚线轮廓。
2. 开火后头顶子弹格立即减少；打空后换弹期间子弹格按比例逐格回充，充满恢复全黄。
3. 玩家阵亡后虚线与子弹格消失；视野迷雾不受影响。
