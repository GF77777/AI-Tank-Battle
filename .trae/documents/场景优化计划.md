## 改动清单

### 1. `game/sprites.py` — 地形矩阵与调色板重绘

- **砖墙**：palette 加 `H` 高光 (210,110,60)；矩阵每块砖上缘改 H 亮线、砖面保留 B，错位砖缝不变——读出"砖"的立体感。
- **钢板**：palette 加 `h` (200,205,215)；矩阵第 1 行内圈改 h 顶边高光（铆钉/焊板结构不变）。
- **河流**：palette 加 `D` 深水 (24,60,150)；`_RIVER` 底部两排加深水点；新增 `_RIVER_B`（波纹相位平移 2px 的第二帧）；`Sprites` 增加 `self.river_b`。
- **森林**：palette 加 `d` 暗缝 (8,70,20)；矩阵改为 4~5 团浅绿树冠簇 + 深绿底 + 暗缝点缀（保持半透明 200 覆盖逻辑不变）。
- **基地**：palette 加 `k` 暗金描边 (120,90,40)；老鹰外轮廓一圈 k。`_BASE_DEAD` 不变。
- **空地地面**：新增 `_GROUND` 16×16——底色 (14,14,18) + 稀疏 (22,22,28) 噪点；`Sprites` 预拼 `self.ground` = 416×416 整张地面 surface（13×13 次 blit 一次完成，之后每帧 1 次 blit）。

### 2. `game/core.py` — `_render_field` 渲染接入

- 地形循环前：`screen.blit(sprites.ground, (0, oy))`（EMPTY 依旧 skip 地形循环）。
- 河流：`img = sprites.river_b if (self.frame // 30) % 2 else sprites.tiles[S.RIVER]`（0.5s 一帧，缓慢流动）。
- 基地光环（`base_alive` 时）：地形绘制后画 `pygame.draw.circle(screen, (120,90,40), 基地中心, 20 + (self.frame // 10) % 3, 1)`——暗金细环缓慢脉动，提示基地位置（不带透明度，零 Surface 开销）。

### 3. `game/level.py` — L2/L3 模板改进（L1 不动）

**LEVEL_2**（保持"河流+森林割裂"主题，打通底部横向回防路）：

- row8 `.BBB.SS.BBB.B` → `.BBB....BBB.B`（去掉两块钢板改空地，底部回防不再绕远）

**LEVEL_3**（钢板要塞主题保留，河流缩短 + 基地围砖加厚）：

- row11 `....BBBB.....` → `....BBBBB....`（基地上方砖墙 4→5 格，保护更完整）

约束自检：行 0 全空（敌人出生行）、玩家出生点 (4,12) 为空、基地 (6,12) 存在且唯一、13×13。
