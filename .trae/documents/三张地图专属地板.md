# 三张地图专属地板计划

## Summary
按现有像素素材风格生成三张 64×64 地板 PNG，并分别用于三张预设地图。地板采用低亮度、低饱和、低对比纹理，不包含箱子、树木、坦克或图标形状；始终绘制在最底层，不影响特殊方块、坦克、子弹和 UI 的辨识度，也不改变任何地形语义。

## Proposed Changes
### 1. 生成三张独立地板 PNG
目标目录：`assets/tiles/`
- `floor_map1.png`：用于「折角回廊」。深蓝灰错缝石砖，基色约 RGB(28,34,40)，砖缝约 RGB(20,25,30)，仅使用 ±4 的轻微色差。
- `floor_map2.png`：用于「十字阵」。低饱和褐灰泥土，基色约 RGB(38,32,28)，使用固定随机种子生成稀疏暗粒与小碎石，无箱子或植被形状。
- `floor_map3.png`：用于「放射阵」。深炭灰方形地砖，基色约 RGB(28,30,34)，大格弱砖缝与少量磨损点，亮度低于钢板和坦克。
- 三张素材均为 64×64、完全不透明、边缘可连续平铺；纹理固定，不使用动态随机或动画。
- 通过临时脚本生成最终 PNG，不在项目中保留生成脚本或测试文件。
