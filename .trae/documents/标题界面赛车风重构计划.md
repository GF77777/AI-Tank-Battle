# 标题界面重构计划（赛车菜单风）

## 概要

按用户提供的参考图（AI 赛车·道具对抗菜单）重构标题界面：纯白大标题 + 单行副标语 + 分割线 + 分区小标签（模式 / 出战配置）+ 左侧黄色竖条的选中样式 + 「坦克」配置行（A/D 直接换车）+ 底部操作提示与绿色「AI 策略：Double DQN 模型」。背景改为纯深色（去掉战场渲染与面板）。

**用户已确认的决策**
1. 配置区只放「坦克」一行（A/D 换轻骑/标准/重装）。
2. 「闯关模式」Enter 直接开战；车库菜单项保留（大图展示页）；**删除坦克选择视图**（避免两处重复选车）。
3. 标题背景纯深色，不再渲染战场。

### 2. `game/core.py` — 常量与字段

- 新增 `ROW_TANK_CONFIG = 4`；标题根视图的选择行数从 `MODE_COUNT(4)` 扩为 5（0~3 菜单项 + 4 配置行），循环取模用 `MODE_COUNT + 1`。
- 删除 `self.tank_select` 字段（`tank_index` 保留，继续与车库同步）。

### 3. `game/core.py` — `handle_event`

- UP/DOWN（START 根视图，即非 garage 且无 notice）：`mode_index = (mode_index + step) % 5`；删除 tank_select 分支。
- LEFT/RIGHT（START 根视图且 `mode_index == ROW_TANK_CONFIG`）：切换坦克——
  `self.tank_index = (self.tank_index + step) % len(S.TANK_ORDER)`；`self.tank_type = S.TANK_ORDER[self.tank_index]`；`audio.play("pickup", 0.4)`。其余情况 LEFT/RIGHT 仍 `return True`（车库分支保留在前）。
- Esc：删除 tank_select 分支；其余不变（根视图 Esc 退出程序）。

### 4. `game/core.py` — `_confirm`

- 删除 `self.tank_select` 分支；`MODE_CAMPAIGN` → 直接 `self.start_game()`（用当前 `tank_type`）。
- `mode_index == ROW_TANK_CONFIG`：Enter 无操作（仅 A/D 调整），`return`。
- MODE_GARAGE / start_notice 分支不变。
