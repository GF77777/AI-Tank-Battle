## Proposed Changes
### 1. 地图 1：浅石板与花草
目标文件：`assets/tiles/floor_map1.png`
- 以 RGB(154,164,153) 附近的灰绿浅石板为底色，砖缝约 RGB(124,139,128)，高光约 RGB(181,190,174)。
- 使用错缝石板作为基础，但加入不同长度的草缝、少量小石子、黄色/米白小花和轻微裂纹。
- 石板只作为低对比背景块，不画成带边框的箱子，不使用橙棕色。

### 2. 地图 2：暖沙、卵石与草丛
目标文件：`assets/tiles/floor_map2.png`
- 以 RGB(194,169,117) 附近的暖沙色为底色，沙纹约 RGB(214,190,137)，土斑约 RGB(166,139,94)。
- 组合柔和沙纹、不规则土斑、2–4px 小卵石和稀疏灰绿草丛，避免当前纯噪点的单一观感。
- 卵石和草丛保持小尺寸、低饱和，不画成可拾取道具或障碍物。

### 3. 地图 3：草地、土斑与小花
目标文件：`assets/tiles/floor_map3.png`
- 以 RGB(126,158,105) 附近的柔和草绿为底色，比绿树冠更浅、更低饱和。
- 组合短草叶、不规则浅土斑、细小石子和少量黄色/米白小花；草地具有明度变化但无大块高对比噪点。
- 不使用圆形树冠图案，不使用与红点敌人提示相近的红色装饰。

### 4. 生成方式与兼容约束
- 三张素材均重新生成为 64×64、完全不透明、可连续平铺的 PNG，直接覆盖同名旧文件。
- 使用固定随机种子和临时生成脚本，保证结果可复现；脚本和测试截图放在临时目录，不留在项目中。
- 单格装饰保持低对比、低密度：小元素源图尺寸以 2–6px 为主，避免 24×24 缩放及摄像机放大后形成大块杂乱图案。
- 保留原文件名，因此无需修改 `sprites.py`、`core.py`、`level.py` 或 `settings.py`。
- 地板不写入 `game.grid`，不影响出生点、通行、子弹、破坏、森林遮挡、道具或 384 维 RL 状态。
