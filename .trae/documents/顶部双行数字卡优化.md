# 顶部 HUD「双行数字卡」优化计划

## Summary
按用户选择的方案，将当前顶部战术卡片改为双行数字卡：小标签在上、大数字／倒计时在下，加入细分隔线和角标，完全移除坦克图标。保留 48px 顶栏、现有信息和战场尺寸。

## Current State Analysis
- [core.py `_render_hud()`](file:///c:/Users/CGF/Desktop/AI坦克大战/game/core.py#L1956-L1993) 当前左侧卡片采用“剩余 + 18px 坦克图标 + 数量”的单行布局，图标来自 `sprites.player_tanks["standard"][S.UP]`。
- 排位右侧卡片采用“安全区 + ZONE 文本”的单行布局；对战、自定义模式不显示右侧卡片。
- [settings.py](file:///c:/Users/CGF/Desktop/AI坦克大战/game/settings.py#L4-L29) 已提供 `HUD_HEIGHT=48`、`PANEL_BG`、`PANEL_BORDER`、黄色和红色，足够完成新样式，无需新增资源。
- `_icon()` 仍被其他 UI 使用；本次仅停止 HUD 调用，不删除共享函数或坦克精灵。

## Proposed Changes
### `game/core.py` — 重写 `_render_hud()` 内部布局
1. **移除坦克图标**
   - 删除 `_render_hud()` 中的 `get_sprites()`、`foe` 图标缓存调用及图标坐标计算。
   - 不修改 `sprites.py`、共享 `_icon()` 或其他页面的坦克图像。

2. **左侧双行数字卡**
   - 卡片使用 `Rect(6, 4, 104, 40)`，深色面板底、1px 统一描边和 4px 圆角。
   - 顶部标签区使用稍亮的深色，底部保留 `PANEL_BG`，中间以细分隔线形成双行层次。
   - 第一行：9px `LIGHT_GRAY` 的“剩余 / LEFT”，左侧配短小黄色标记；右上角增加黄色 L 形角标。
   - 第二行：20px 白色存活敌人数，左对齐并沿用轻量双绘粗体效果，数字成为主要视觉焦点。
   - 敌人数仍按 `versus_foes` 中 `alive` 的数量计算。

3. **右侧双行安全区卡**
   - 仅在排位模式显示；最小宽度 142px，宽度根据两行文本的最大实际宽度动态增加，右边距 6px。
   - 第一行：9px 灰色“安全区 / SAFE ZONE”，红色短标记和红色 L 形角标。
   - 第二行：18px 红色 `ZONE n s / ZONE MAX`，左对齐。
   - 保留现有倒计时与最大缩圈判断，不添加进度条或新数据。

4. **保持不变**
   - 顶栏继续填充 `HUD_BG`，底部分隔线使用 `PANEL_BORDER`；`HUD_HEIGHT`、战场起点、镜头和小地图不变。
   - 不修改 `_TEXTS`、字体函数、颜色常量、玩法状态、AI 观测或训练逻辑。

## Assumptions & Decisions
- 用户已在三套方案中选择「双行数字卡」。
- 装饰仅使用几何线条和明暗分区，不再使用任何坦克、敌人士兵或类似功能的图标。
- 双行布局是本次主要差异化：标签弱化、数值强化，而非继续堆叠装饰元素。
