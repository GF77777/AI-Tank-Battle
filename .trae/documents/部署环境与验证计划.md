## Proposed Changes

### 1. 修正 `requirements.txt`（[requirements.txt](file:///c:/Users/CGF/Desktop/AI坦克大战/requirements.txt)）

**What**：让版本约束与本机 Python 3.8 实际兼容，并删除未使用的 opencv。

**Why**：当前文件会让 `pip install -r requirements.txt` 在 Python 3.8 上失败（numpy 1.26 无 3.8 wheel）；opencv 是死依赖。

**How**：
```diff
 pygame>=2.5.0
 torch>=2.2.0
-numpy>=1.26.0
-opencv-python>=4.8.0
+numpy>=1.24.0
```

### 2. 修正 `README.md` 的 Python 路径（[README.md](file:///c:/Users/CGF/Desktop/AI坦克大战/README.md#L7-L13)）

**What**：把写死的 `C:\Users\CJP\...\Python312\python.exe` 替换为通用 `python` 命令。

**Why**：路径指向另一台机器的用户目录，本机根本不存在，会让读者复制粘贴后报错。

**How**：把快速开始段的两行改为
```
python -m pip install -r requirements.txt
python main.py
```
并把括号注释 `（Python 3.12）` 改为 `（Python 3.8+）`。

### 3. 端到端验证（无文件改动）

**What**：用 `evaluate.py` 跑 5 局贪心评估。

**Why**：这一步会真实触发完整链路——加载 `models/dqn_tank.pth` → 构建 `VersusEnv` → 跑 4 帧/决策循环 → 输出胜率/击杀/奖励/步数/得分 → 写入 `models/eval_result.csv`。任何环节崩了都会立刻暴露。

**How**：
```powershell
python evaluate.py --episodes 5 --seed 1
```
预期：约 30 秒内完成，打印 5 行 `eval ep...` 明细和一行汇总（胜率、平均击杀、平均奖励、平均步数、平均得分）。

## Assumptions & Decisions

| 决策 | 理由 |
|---|---|
| 不升级 Python 到 3.12 | 用户已选择沿用 3.8；当前依赖全部可用；升级收益小、代价大 |
| 不新建 venv | 用户已选择沿用现有环境；当前包是全局安装且能跑 |
| 删除 opencv 依赖 | 全项目 grep 确认无 `import cv2`；保留会误导未来部署者 |
| numpy 降到 `>=1.24.0` 而不是 `>=1.26.0` | Python 3.8 上限就是 numpy 1.24.x；这是事实约束而非偏好 |
| 只验证 evaluate.py 不验证 train.py | 用户已选 evaluate.py 5 局；train.py 5 局训练耗时长且无必要（评估已能覆盖模型加载与环境交互） |
| 不验证 main.py / play_ai.py | 它们需要弹真实窗口且要手动关闭，不适合自动化部署验证 |
