# 多辆坦克计划（开局前 3 选 1）

## 1. 目标

标题界面选「闯关模式」后进入坦克选择视图，3 辆参数差异坦克任选其一开始游戏。纯人类模式特性；RL 训练/评估环境固定使用「标准型」，数值与现状逐位一致。

## 2. 现状分析（已核实）

- 玩家参数全部硬编码在 [settings.py](../game/settings.py)：`PLAYER_SPEED=2.0`、`PLAYER_FIRE_COOLDOWN=21`、`PLAYER_MAX_BULLETS=2`、`PLAYER_CHARGE_FRAMES=45`、`PLAYER_CHARGE_COOLDOWN=42`
- [entities.py](../game/entities.py) `PlayerTank.__init__(x, y)` 只读 `S.PLAYER_SPEED`；`Tank.__init__` 读 `S.PLAYER_FIRE_COOLDOWN`
- [core.py](../game/core.py) 引用点：`S.PLAYER_MAX_BULLETS`（`player_fire`/`start_charge`）、`S.PLAYER_CHARGE_FRAMES`（`release_fire`/蓄力条渲染）、`S.PLAYER_CHARGE_COOLDOWN`（`player_fire`）
- 选择界面可复用：`_menu_button()`（按钮条）、`start_notice` 标题内子视图模式（无需新增状态机状态）
- 换色精灵机制现成（[sprites.py](../game/sprites.py) 调色板字典，玩家黄/敌人灰/突击红为先例）

## 3. 坦克设计（围绕「单发即毁」与蓄力炮联动）

| 型号 | key | 速度 | 冷却 | 弹上限 | 蓄力帧 | 定位幻想 |
|---|---|---|---|---|---|---|
| 轻骑 | scout | **2.6**（+30%） | 21 | **1** | 45 | 打了就跑的游走位：速度换弹量，容错最低 |
| 标准 | standard | 2.0 | 21 | 2 | 45 | 现状基准，一行代码不动数值 |
| 重装 | heavy | **1.6**（-20%） | **26** | **3** | **30**（0.5s） | 站桩炮台：跑不过突击型（同 1.6），但蓄力炮转得飞快 |

设计决策：
- 重装速度 1.6 = 突击型速度 → 「会被快车追上」是新威胁，配合蓄力 30 帧鼓励站桩开炮，与蓄力炮机制强联动（答辩叙事：同一机制在不同 build 下的手感分化）。
- 轻骑弹量 1 是硬约束：开火后必须等命中/消失，逼走位。
- 三辆共用同一套碰撞/无敌/复活规则，只改上表 5 个数值。

## 4. 改动清单

### 4.1 `game/settings.py` — 新增坦克参数表

```python
# ---------- 玩家坦克型号（开局前选择；训练/评估固定 standard） ----------
TANK_TYPES = {
    "scout":    {"speed": 2.6, "fire_cooldown": 21, "max_bullets": 1,
                 "charge_frames": 45, "charge_cooldown": 42},
    "standard": {"speed": 2.0, "fire_cooldown": 21, "max_bullets": 2,
                 "charge_frames": 45, "charge_cooldown": 42},
    "heavy":    {"speed": 1.6, "fire_cooldown": 26, "max_bullets": 3,
                 "charge_frames": 30, "charge_cooldown": 42},
}
TANK_ORDER = ["scout", "standard", "heavy"]   # 选择界面顺序
DEFAULT_TANK = "standard"
```

原 `PLAYER_*` 常量保留（RL 环境语义不动），作为 standard 的事实来源被 `TANK_TYPES["standard"]` 引用或保持一致。

### 4.2 `game/entities.py` — PlayerTank 按型号实例化

```python
class PlayerTank(Tank):
    def __init__(self, x, y, tank_type=DEFAULT_TANK):
        cfg = S.TANK_TYPES[tank_type]
        super().__init__(x, y, S.UP, cfg["speed"], is_player=True)
        self.tank_type = tank_type
        self.fire_cooldown_max = cfg["fire_cooldown"]
        self.max_bullets = cfg["max_bullets"]
        self.charge_frames_max = cfg["charge_frames"]
        self.charge_cooldown = cfg["charge_cooldown"]
        self.invincible = S.RESPAWN_INVINCIBLE
```

（`Tank.__init__` 的默认 `fire_cooldown_max` 逻辑保留给敌人，玩家被 PlayerTank 覆盖。）

### 4.3 `game/sprites.py` — 轻骑/重装换色精灵

复用现有玩家模板 + 新调色板生成 `player_tank_scout`（亮黄白）、`player_tank_heavy`（橙棕），`Game._render_field`/`_render_hud` 生命图标按 `self.player.tank_type` 选对应精灵表。

### 4.4 `game/core.py` — 参数引用改读实例属性

- `player_fire()`：`S.PLAYER_MAX_BULLETS` → `self.player.max_bullets`；`S.PLAYER_CHARGE_COOLDOWN` → `self.player.charge_cooldown`
- `start_charge()`：同上改 `self.player.max_bullets`
- `release_fire()`：`S.PLAYER_CHARGE_FRAMES` → `self.player.charge_frames_max`
- 蓄力条渲染：`S.PLAYER_CHARGE_FRAMES` → `self.player.charge_frames_max`
- `_reset_battle`：`PlayerTank(px, py, self.tank_type)`；`__init__` 新增 `self.tank_type = S.DEFAULT_TANK`、`self.tank_select = False`、`self.tank_index = 1`（默认标准）

### 4.5 `game/core.py` — 坦克选择视图（复用 start_notice 模式，不加新状态）

**输入**（`handle_event` / `_confirm`）：
- START + 模式列表按 Enter 选中「闯关模式」→ `self.tank_select = True`（不再直接 `start_game()`）
- `tank_select` 激活时：上下键改 `tank_index`（优先于 mode_index 分支）；Enter → `self.tank_type = TANK_ORDER[tank_index]` + `start_game()`；Esc → 退回模式列表（`tank_select=False`，不退出程序）
- 「观战 AI / 训练曲线」的 start_notice 行为不变；两者互斥（进 tank_select 时清 start_notice，反之亦然）

- 不加第 4 辆坦克、不做坦克解锁/熟练度（撞 GDD 不做清单）。

## 6. 验证

1. **参数实例化**（headless 断言）：三种型号 PlayerTank 的 speed/fire_cooldown_max/max_bullets/charge_frames_max 与参数表一致；standard 各值 == 旧常量。
2. **玩法差异**（headless）：轻骑第 2 发打不出；重装场上可同时 3 发；重装蓄力 30 帧即满、蓄力条比例按 30 计算。
3. **界面流转**（headless 模拟按键 + 截图目检）：模式列表 → 坦克选择 → 上下键切换 → Enter 进 PLAYING（HUD 生命图标用对应精灵）；Esc 退回模式列表；start_notice 与 tank_select 互斥。
4. **回归**：`evaluate.py --episodes 3 --seed 1` 输出与基线逐位一致。
5. **真机**：`python main.py` 三辆各玩一遍感受差异。
