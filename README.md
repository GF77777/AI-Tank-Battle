# AI 坦克大战

复古像素风 2D 坦克对战 + Double DQN **自博弈**训练管线：玩家在对称竞技场里与 3 个自己训练出来的 AI 大混战（FFA 1v3）。全部美术与音效由代码生成，零外部素材。

仓库地址：<https://github.com/GF77777/AI-Tank-Battle>

## 快速开始

```powershell
git clone https://github.com/GF77777/AI-Tank-Battle.git
cd AI-Tank-Battle

# 安装依赖（Python 3.8+）
python -m pip install -r requirements.txt

# 开始游戏
python main.py
```

窗口 832×928（逻辑分辨率 416×464 的 2 倍整数放大），最近邻取样保持像素锐利。也可以双击根目录的 `AI坦克大战.lnk` 启动（不显示 Python 控制台）。

## 操作

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 移动（启动时已为本窗口禁用输入法，菜单同样支持 W/S） |
| J | 普攻（**自动攻击**：射程内有可视敌人时车头自动转向最近目标再开火，无目标则朝原车头） |
| K | 立即释放技能：标准=穿甲弹（直线不追踪、穿砖穿人、被钢板挡）、轻骑=无伤疾冲、重装=全向冲击波；技能与普攻独立冷却，不耗弹匣。轻骑可存 2 次，每 0.7s 恢复 1 次；右下角显示技能次数与冷却秒数 |
| Esc | 暂停（游戏中）；标题与结算界面返回或退出 |
| 上下键 + Enter | 选择菜单项（仓库内左右键翻页、Enter 选用坦克） |
| A/D（标题界面） | 调整出战配置：坦克、人数（2~4）、地图 |
| 鼠标左键 | 点击菜单/仓库箭头/暂停项/设置项（结算界面任意点击重开） |
| Enter | 确认 / 重新开始 |

## 玩法：竞技场大混战

- 17×17 四向对称竞技场 ×3 张预设图（折角回廊 / 十字阵 / 放射阵），**最外层无钢墙**（边界即屏幕边缘，坦克/子弹出界被拦/消亡）、围绕毒圈设计、中心开阔决斗场、**全图草地加密**（44/40/12 格，走廊口/十字臂/放射臂均设伏击点），每局随机抽取，无基地：**2 人局对角单挑、3 人局三角、4 人局四角**，玩家之外为 DQN 驱动的 AI（头顶红色字母 A/B/C），**AI 之间也互相攻击**。四边中点钢板掩体遮挡出生直线（不可摧毁） + 出生 2s 无敌双保险。
- **战争迷雾**：圆形视野半径 6 格，视野外区域涂黑、敌人/子弹/道具不可见（玩家与 AI 同规则），草地单向隐身保留叠加。
- 每方 **1 条命、100 点 HP**（`VERSUS_LIVES=1`、`VERSUS_HP=100`）：按攻击来源扣除不同血量，随后 0.5 秒无敌并沿子弹方向击退 4px；**HP 归零即淘汰，无复活**。全灭 AI 即胜利，分数 = 每次有效命中 ×100。
- **道具系统**：加血（回复 34 HP）/ 火力（冷却 ×0.7，叠 2 层）/ 护盾（无敌 5s）/ 地雷（踩中造成 34 伤害）。每 10 秒随机空格刷 1 个（场上最多 2 个），淘汰对手时死亡格掉落 1 个（无地雷，最多 1 个），15 秒未拾取消失；玩家与 AI 都能捡。
- **毒圈收缩（逐圈推进）**：开局 6s 全图安全，之后每 3s 从外向内缩 1 圈（半径 8→7→…→0，8 圈共 24s），圈外格子罩红、每 1.5s 造成 34 伤害（无视无敌/护盾）。强制遭遇战，HUD 右上角显示倒计时；**下一圈位置红色虚线常显预告**；收缩前 3s 弹公告「毒圈即将收缩」、每次收缩播报当前半径。
- **公告与击杀播报**：公告队列（HUD 下方居中黑底胶囊）；击杀播报（右上角滚动最近 3 条，如「A 淘汰了 玩家」「毒圈 淘汰了 B」，含子弹/地雷/毒圈来源）。
- **草地可埋伏**：站在草地里的坦克**看得见外面，外面看不见里面**——草地外的对手既看不到草地里的坦克，AI 观测里也会把它隐去。
- 三辆出战坦克（100 HP 下伤害数值即百分比）：**轻骑**（普攻 20%，自动二连发·射程 2.5 格，K=无伤疾冲 2 格，可存 2 次，穿坦克与钢板、撞碎砖墙）、**标准**（普攻 34%，单发射程 3.5 格，K=50% 穿甲弹，射程 8 格·直线穿砖穿人）、**重装**（普攻 40%，扇形冲击半径 2 格，K=60% 的 360° 冲击波，r=2 格）。AI 对手**随机三款坦克**且可用技能（规则触发：冷却好且目标在技能范围内即释放）；训练/评估环境恒标准型。
- **弹匣换弹（玩家与 AI 同规则）**：轻骑 3 发 / 标准 4 发 / 重装 2 发（burst 一次扳机耗 1 发），打空**自动换弹**（轻 1s / 标 1.5s / 重 2s），换弹期间不能射击；HUD 血条下方显示弹匣点与换弹进度。技能不耗弹匣；换弹中不能使用穿甲弹或冲击波，轻骑仍可疾冲。
- **打击反馈**：命中闪白、屏幕震动（不影响 HUD）、像素火花与碎屑、弹道尾迹、疾冲残影、枪口火焰、淘汰爆炸与冲击波环。

## AI 自博弈训练与评估

```powershell
# 训练（自博弈 FFA：学习者与 3 个对手共用同一份参数、共享 ε；默认 5000 局）
python train.py --episodes 5000

# 贪心评估（学习者与对手均 ε=0，固定 seed 可复现）
python evaluate.py --episodes 20 --seed 1

# 观看 4 个 AI 自博弈互殴（玩家侧也由同一模型驱动）
python play_ai.py

# 生成训练曲线图（models/train_curve.png）
python plot_curve.py
```

- **状态向量 384 维**：自身 8 + 基地 1（恒 0）+ 对手 4×7 + 子弹 8×5 + 地图 17×17 + 道具 3×4 + 元信息 6。
- **10 个离散动作**，每 4 帧决策一次（约 15 次/秒）。
- **网络结构 384 → 256 → 256 → 10**，Double DQN（online 选动作、target 估值，每 500 次更新硬同步），Huber loss。
- 训练超参：γ=0.99、Adam lr=5e-4、batch 128、回放池 200,000、每 4 个决策步更新一次、ε 1.0→0.05 线性衰减。
- 奖励（`game/settings.py` 的 `VS_R_*`）：淘汰对手 +500、被淘汰 −500、每决策步 −0.2、移动 +0.2、蹲点 −0.2、圈外 −2.0、贴圈 −0.5、开火 −1.0、命中 +4.0。
- 训练/评估默认 `SDL_VIDEODRIVER=dummy` 无窗口运行。

当前训练累计 5000 局，最终 ε=0.05（`models/train_log.csv`）。每 200 局的贪心评估记录（`models/eval_log.csv`，20 局，自博弈镜像）：

| 训练局数 | 胜率 | 平均击杀 | 平均奖励 |
|---|---|---|---|
| 2000 | 35% | 1.20 | 218.6 |
| 3000 | 45% | 1.40 | 393.9 |
| 4600 | 45% | 1.45 | 442.2 |
| 5000 | 20% | 0.60 | −156.5 |

4 人镜像 FFA 理论上限约 25%，训练中段多次接近该水平，末段出现自博弈典型震荡，数据如实记录。旧规则（3 命制·248 维 / 260 维闯关时代）模型归档在 `models/legacy/`。

## 性能与加载

- **后台预加载**：启动标题界面时就在后台加载 DQN 模型，首次点击对战/排位不再卡顿（原同步导入 PyTorch 约 2.4s、构造网络与回放池约 1s）。
- **加载提示**：模型未就绪时显示「AI 模型加载中…」，完成后自动进入；Esc 取消进入，后台继续加载并缓存。
- **模型缓存**：同一进程内重开、返回标题再进入不重复加载。
- **推理轻量化**：真人对局使用 `buffer_capacity=0`，不分配约 308MB 的训练回放数组；训练脚本仍使用完整回放池。
- **异常提示**：模型文件缺失或损坏时给出明确文案，不会卡在加载页。

## 发布与图标

- 游戏窗口与任务栏使用坦克图标（`assets/tank.ico` 与代码生成的窗口图标）。
- 从终端启动时设置了独立任务栏标识，任务栏按钮显示游戏图标而不是终端图标。
- `AI坦克大战.lnk` 使用 `pythonw` 启动，无控制台窗口。

## 项目结构

```
main.py            人类玩家入口（标题 / 暂停 / 结算）
play_ai.py         4 AI 自博弈观战
train.py           自博弈 DQN 训练（日志写入 models/）
evaluate.py        贪心评估（可复现）
plot_curve.py      pygame 自绘训练曲线
game/
  settings.py      全部数值常量（含 VS_R_* 对战奖励）
  core.py          状态机、碰撞、对战逻辑、渲染、打击反馈
  env.py           VersusEnv 自博弈环境（build_foe_state 状态构造）
  entities.py      坦克（玩家/AI 对手共用）、子弹、爆炸
  level.py         对战竞技场地图
  sprites.py       字符像素矩阵绘制精灵
  audio.py         numpy 合成音效（无音频设备自动静音）
  avatars.py       头像池与缓存
  prefs.py         prefs.json 读写与校验
  playtest.py      试玩会话日志
ai/dqn.py          QNet / ReplayBuffer / DQNAgent
docs/              GDD、UI 设计规范、课程四份文档
models/            模型、训练日志、曲线图、legacy 归档
assets/            坦克图标与可选贴皮
```

代码规模约 5200 行 Python（`game/core.py` 约 2900 行）。

## 试玩日志

从 `main.py` 启动的人类对局会自动记录到 `playtest/sessions.csv`（每局一行）：`session`（局 ID）、`result`（win/lose）、`lose_reason`、`score`、`kills`、`lives_left`、`time_sec`。AI 训练与评估不写此文件。删除整个 `playtest/` 目录即可清空记录。

## 设计取舍

- 纯对战、无闯关：把"训出来的 AI"从观战对象变成可对战的对手，FFA 规则下战局可读、节奏可控。
- AI 对手技能由游戏规则触发，不使用独立技能动作；普攻动作空间与训练分布一致。
- 素材默认全部代码生成：换机器不丢资源，答辩现场无外部依赖；可选在 `assets/tanks/` 放 28×28 朝上透明 PNG 给坦克贴皮（按型号命名，如 `scout.png`），缺图自动回退代码矩阵。
- 游戏分数与 RL 奖励是两套独立数值，改游戏分数不影响训练。
