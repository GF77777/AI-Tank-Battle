## 2. 测试方法

1. **静态检查**：`python -m compileall main.py game ai` 确认语法与导入无错误。
2. **无头功能验证**：设置 `SDL_VIDEODRIVER=dummy`，用脚本驱动 `Game.update()` / `Game.render()`，逐项断言状态、坐标、计数与像素。
3. **可复现评估**：`python evaluate.py --episodes N --seed S`，固定种子下同模型结果一致。
4. **接口回归**：`VersusEnv.reset()/step()` 检查 384 维、有限值、奖励与 done 语义。
5. **异常注入**：临时改名/破坏模型文件，验证缺失与损坏提示；用可控阻塞 loader 验证异步加载。

## 4. 缺陷与修复记录

| 编号 | 问题 | 原因 | 修复 |
|---|---|---|---|
| D-01 | 点击对战/排位明显卡顿 | 主线程同步导入 PyTorch、构造 DQN、分配回放池 | 后台预加载 + 加载提示 + 推理零容量回放池 |
| D-02 | 负向震屏把战场画进 HUD 区域 | blit 未裁剪 | 战场绘制设置并恢复 clip |
| D-03 | 护盾环在草地边缘泄露位置 | 29×29 环越出 24px 草格 | AI 环纳入迷雾可见性控制 |
| D-04 | 续训时 ε 被重置 | 续训未衔接已有决策步 | 按已训练步数恢复衰减 |
| D-05 | 遗留 260 维模型日志混入当前日志 | 维度变更未隔离 | 旧日志归档到 `models/legacy/` |
| D-06 | 音量断言在 0.09 处失败 | SDL 对音量离散量化 | 调整测试容差，生产公式不变 |

## 5. 结论

- 启动、对战主链路、AI 训练评估、设置持久化、异步加载与异常路径全部通过。
- 已知遗留项均不阻塞交付：评估样本 20 局方差偏大、自博弈胜率存在震荡、手感参数未做大规模实机调优。
- 建议后续：50 局以上评估、引入快照池、规则冻结后完整重训 5000 局。
