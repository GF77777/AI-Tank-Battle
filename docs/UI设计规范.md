# 《AI 坦克大战》UI 设计规范

> 版本：v2.8（作品集/答辩版）
> **v2.8 变更：对战入口新增真实模型加载提示，就绪后自动进入；加载中 Enter/点击不重复触发，Esc 只取消进入并保留后台缓存。**
> v2.7 变更：设置页扩为八行，新增总音量与音效音量百分比；24px 紧凑行高，支持键盘/鼠标调节并持久化。
> v2.6 变更：三型号开火音色差异化，普通中弹与淘汰使用两级音效；保留 FC 合成质感，单次播放音量独立。
> v2.5 变更：无敌时坦克始终可见，白星替换为青蓝护盾环；20 帧呼吸、最后 12 帧仅环体提示闪烁，暂停冻结且不泄露草地/迷雾位置。
> v2.4 变更：全套像素战斗特效——补齐枪口、尾迹、火花、碎屑、淘汰爆燃和三型号技能表现；统一草地/迷雾遮挡与衰减震屏，HUD 保持稳定。
> v1.1~v1.9 变更：见 git 历史（闯关模式时代）。
> v2.0 变更：对战模式（对应 GDD v2.1）——标题菜单第 5 项「对战模式」，行距 34→32；AI 对手头顶红色字母 tag。
> v2.1 变更：纯对战收敛（对应 GDD v3.0）——标题菜单收敛为 3 项（对战模式/训练曲线/坦克仓库）+ 出战配置行，纵向坐标重排；HUD 删除关卡号与道具倒计时条，「剩余敌人」改为「存活 AI 数」；结算删除全部通关/下一关/基地被毁分支；文案表同步清理。
> **v2.2 变更：生命格 + 草地隐藏（对应 GDD v3.1）——HUD 右侧改为「3 个生命格 + 生命图标 ×N」；坦克头顶新增 8×3 血格；草地覆盖层不透明（alpha 255），并采用「玩家在草地内/外」两套绘制顺序；对手 tag 上移到 y-18 避让血格。**
> **v2.3 变更：真实 100 HP——HUD 中央显示玩家百分比血量与连续比例条；坦克头顶改为 26×3 连续比例血条；营地同步三型号普攻与技能伤害。**
> 逻辑分辨率 **416×464**（战场 416×416 + HUD 48），窗口 **832×928**（2 倍整数放大，最近邻）。
> 所有坐标均为**逻辑像素**，绘制时不做任何缩放；放大只在 `present()` 一次完成。

## 1. 界面清单与状态流转

```
                 ┌──────────────────────────────────────┐
                 │  标题 TITLE                          │
                 │  · 对战模式      → PLAYING           │
                 │  · 训练曲线      → 外部 script 提示   │
                 │  · 坦克仓库      → 仓库子视图(4.1)    │
                 └──────────────┬───────────────────────┘
                                │ Enter
                                ▼
                      ┌───────────────────┐   Esc    ┌──────────────────┐
                      │ 游戏 PLAYING +HUD │ ───────► │ 暂停 PAUSED      │
                      │                   │ ◄─────── │ 继续/重开/回标题 │
                      └─────┬───────┬─────┘  Enter   └──────────────────┘
                 全灭 AI 对手        │       │ 生命耗尽
                                ▼       ▼
                      ┌────────────┐ ┌────────────┐
                      │ 胜利 WIN   │ │ 失败 LOSE  │
                      │ Enter→重开 │ │ Enter→重开 │
                      └────────────┘ └────────────┘
```

**状态常量**（`game/core.py`）：`STATE_START` / `STATE_PLAYING` / `STATE_PAUSED`（新增） / `STATE_WIN` / `STATE_LOSE`。

## 2. 统一视觉基线

### 2.1 网格与对齐

* UI 元素一律对齐 **8px** 网格；文字基线取"居中 = y + (行高 - 字高) / 2"。
* HUD 高 48px；战场原点 `y = 48`，所有游戏实体绘制时加 `oy = S.HUD_HEIGHT` 偏移（现有实现已如此，不要改）。

### 2.2 调色板（**直接引用 `settings.py` 现有常量，不新增颜色**）

| 用途 | 常量 | RGB | Hex |
|---|---|---|---|
| 战场背景 | `S.BLACK` | (0,0,0) | #000000 |
| HUD 背景 | `S.HUD_BG` | (24,24,32) | #181820 |
| 主强调（玩家/标题） | `S.YELLOW` | (240,200,60) | #F0C83C |
| 危险（失败/敌人） | `S.RED` | (220,50,40) | #DC3228 |
| 正向（提示/胜利） | `S.GREEN` | (80,200,80) | #50C850 |
| 主要文字 | `S.WHITE` | (255,255,255) | #FFFFFF |
| 次级文字 | `S.GRAY` | (120,120,120) | #787878 |
| 菜单未选中项 | `S.LIGHT_GRAY` | (176,176,176) | #B0B0B0 |
| 分割线 | `S.DARK_GRAY` | (60,60,60) | #3C3C3C |

> 结论：全项目 UI 绘制统一引用上表，杜绝硬编码色值（v1.2 新增 `S.LIGHT_GRAY` 用于菜单未选中项）。v1.8 例外：菜单选中底条 `(255,255,255,14)` 为允许的硬编码透明度色（与既有 `(240,200,60,28)` 同类处理）。

### 2.3 字号（复用 `get_font(size)`）

| 层级 | 字号 | 用途 |
|---|---|---|
| 主标题 | 40 | 游戏名、"胜 利"、"游戏结束" |
| 次标题 | 28 | 暂停标题、模式名 |
| 正文 | 20 | 菜单项、结算数据、操作提示 |
| 小字 | 18 | HUD 数值 |
| 说明 | 14 | 一句话定位、副提示 |
| 版权 | 12 | 底部署名 |

字体来源：系统 `Microsoft YaHei / SimHei`，缺失时自动回退英文（现有 `_detect_cjk_font()` 机制，不打包字体文件）。

## 3. HUD 布局（y = 0～48）

```
┌──────────────────────────────────────────────────────────────┐
│ 剩余敌人       生命 / HP                 安全区               │
│    3          100%  ▰▰▰▰▱▱               ZONE 3s             │
└──────────────────────────────────────────────────────────────┘
  (6,4,104,40)   (116,4,136,40)             右侧对齐
```

| 元素 | 位置 | 样式 |
|---|---|---|
| 分割线 | (0,47)-(416,47) | `S.PANEL_BORDER` 1px |
| 剩余敌人卡片 | (6,4,104,40) | 双行卡片：上行小标签，下行存活 AI 数；`S.YELLOW` 角标 |
| 玩家血量卡片 | (116,4,136,40) | 上行「生命 / HP」，下行显示 `hp / max_hp` 的整数百分比与连续比例条；`S.GREEN` 强调 |
| 安全区卡片 | 右侧 `(SCREEN_WIDTH-6-zone_w,4,zone_w,40)` | 双行卡片，显示安全区倒计时；`S.RED` 角标，仅对战模式显示 |

> v2.3 说明：所有坦克真实拥有 100 HP，因此 HUD 百分比与当前 HP 数值一一对应。比例按 `hp / max_hp` 计算并钳制在 0～1；不再绘制三格血或生命数。

**布局理由**：左侧保留剩余敌人数，中央突出玩家生存状态，右侧保留毒圈信息；三张卡片分离，避免余光读取时互相干扰。

```

                     y=124   复古像素坦克大战 · 击败你训练的 AI   字号14 S.GRAY
                     y=152   ─────────── 分割线 1px S.DARK_GRAY，x=88..328
                     y=168   模 式                                字号12 S.GRAY，x=88
                     y=188   │ 对 战 模 式                        行 240×30 行距32，共 3 项（v2.1）
                     y=220     训 练 曲 线                        选中：白5%底条 + 左缘3px黄竖条 + 黄字
                     y=252     坦 克 仓 库                        未选中：S.LIGHT_GRAY
                     y=292   ─────────── 分割线
                     y=308   出 战 配 置                          字号12 S.GRAY，x=88
                     y=322   坦 克                 ◀ 标 准 ▶      标签居左16号；值居右16号黄+三角箭头

                     y=386   AI 策略：Double DQN 模型             字号12 S.GREEN 居中
```

| 元素 | 规格 |
|---|---|
| 背景 | **纯黑 `S.BLACK`**（标题不渲染战场与 HUD；暂停/结算仍压暗战场） |
| 内容列 | x=88..328（宽 240），分区标签、菜单行、配置行、分割线全部对齐此列 |
| 主标题 | 字号 40，`S.WHITE`，水平居中，y=64 |
| 一句话定位 | 字号 14，`S.GRAY`，单行，y=124，居中 |
| 分割线 | 1px `S.DARK_GRAY`，x=88..328，y=152 / 292 / 360 |
| 分区标签 | 字号 12，`S.GRAY`，x=88：「模 式」y=168、「出 战 配 置」y=308 |
| 菜单行（`_menu_button()`） | 宽 240 高 30（x=88），行距 32，起始 y=188，共 **3** 项（v2.1）；选中：白 5% 底条 `(255,255,255,14)` + 左缘 3px `S.YELLOW` 竖条 + `S.YELLOW` 字（x+14）；未选中：`S.LIGHT_GRAY`（x+14）。暂停菜单复用同一函数 |
| 坦克配置行（`_render_config_tank()`） | y=322，高 30：标签「坦 克」16 号（未选中 `S.WHITE` / 选中 `S.YELLOW`）x+14；值区右对齐：左三角 polygon + 型号名 16 号 `S.YELLOW` + 右三角 polygon（尖端与列右缘齐平）；选中态底条+竖条同菜单行 |
| 键盘操作 | W/S 或上下键在 **4 行**间循环（3 菜单项 + 配置行，`ROW_COUNT=4`）；配置行上 A/D 或左右键换坦克（播放 pickup 音效 0.4，同步 `tank_type`/`tank_index`）；Enter 确认（配置行 Enter 无操作）；Esc 退出程序 |
| 底部 | 操作提示字号 12 `S.GRAY` y=370；「AI 策略：Double DQN 模型」字号 12 `S.GREEN` y=386（呼应答辩叙事） |

**三行菜单 + 配置行的行为**

| 行 | 行为 |
|---|---|
| 对战 / 排位 | 模型后台预加载后就绪即进入对应竞技场；点击时仍在加载则显示 `AI 模型加载中… → 完成后自动进入`。模型缺失提示 `未找到 models/dqn_tank.pth → 请先运行 python train.py 训练`，损坏或读取异常提示 `AI 模型加载失败 → 请检查模型文件或重新训练`；缺失/失败页 Enter 或点击返回 |
| 训练曲线 | 提示：`运行 python plot_curve.py 生成 models/train_curve.png`；Enter 返回 |
| 坦克仓库 | 进入坦克仓库视图（4.1），左右翻页浏览，Enter 选用后 Esc 返回列表 |
| 坦克配置行 | A/D 换车；与车库选用互通（共用 `tank_type`/`tank_index`） |

**模型加载交互**：加载页首行黄色、说明行白色，不显示虚假进度；就绪后自动进入本次等待的对战或排位。加载中 Enter 和鼠标点击不重复开局，Esc 仅取消本次自动进入，后台继续完成并缓存；取消后再次点击可直接使用缓存，或重新挂接等待模式。

> 设计取舍：不在游戏内启动子进程，避免打包与权限问题；用"指纹式提示"把 AI 能力暴露给评委就够了。观战需求由 `python play_ai.py`（4 AI 自博弈）承接，不占菜单位。

「坦克仓库」按 Enter 后进入（用 `garage` 标志；与提示页互斥，tagline 隐藏让位）。展示 3 辆玩家坦克的大图与参数，可直接选用作为出战坦克（Enter 选用后仍留在仓库，Esc 返回列表）。

y=222   ◀          ▶              三角箭头 polygon，x=中心±88~100
y=272   型号名（当前选用时后缀「· 使用中」）  20号 居中

## 5. 暂停界面（PAUSED）

| 元素 | 规格 |
|---|---|
| 遮罩 | 全屏 `(0,0,0,160)` |
| 面板 | `(24, 140, 368, 260)`（与标题面板同 x/w，v1.2 统一） |
| 标题 | "暂 停"，字号 28，`S.WHITE`，y=166 居中 |
| 菜单 | 3 项 `_menu_button()`（继续 / 重新开始 / 返回标题），宽 200 居中，行高 36，起始 y=224；选中态规格同第 4 章 |
| 提示 | "上下键 选择   Enter 确认   Esc 继续"，字号 14，`S.GRAY`，y=362 居中（面板内底部） |

**按键规则（与现有行为不冲突）**

* 游戏中按 Esc → 暂停（**不再直接退出程序**）。
* 暂停中 Esc → 继续；Enter → 执行选中项。
* 只有"返回标题"会重置本局进度；"继续"不丢任何状态。

### 5.1 设置页（标题 / 暂停共用）

| 行 | 设置项 | 操作 |
|---|---|---|
| 0 | 音乐 | A/D、点击或 Enter 开关；当前无 BGM |
| 1 | 音效 | A/D、点击或 Enter 开关 |
| 2 | 总音量 | A/D、左右键或点击行左/右半区减/加 10% |
| 3 | 音效音量 | 同总音量 |
| 4 | 人数 | 沿用 2～10 人循环调整 |
| 5 | 对手名字 | 开关对手头顶名字 |
| 6 | 键位 | Enter/点击进入键位子页 |
| 7 | 返回 | Enter/点击返回来源页 |

* 面板沿用 `(24,104,368,312)`；列表首行 y=160，行高 24、行距 28，末行底部 380，底部提示 y=392。
* 两条音量以整数百分比显示，范围 0～100%、默认 100%，边界钳制不循环，Enter 不调整；音量与人数值两侧显示小三角。
* 调整后立即写入 `prefs.json` 并播放确认音，后续播放按新音量生效；Esc 返回标题或暂停菜单，无音频设备时操作保持静默且不报错。

| 项 | 规格 |
|---|---|

## 7. 战场内反馈规格

| 事件 | 反馈 | 参数 |
|---|---|---|
| 玩家开火 | 轻骑清脆 / 标准均衡 / 重装厚重的分层方波音效 + 炮口白黄火焰 | 音色 55/85/130ms；普通 8×8 / 3 帧；穿甲 10×10 / 4 帧 |
| AI 开火 | 同型号低音量的分层射击音效 + 同款炮口火焰 | 玩家与 AI 共用型号音色，播放 Channel 独立控制音量 |
| 普通弹 / 穿甲弹飞行 | 弹体后下方短尾迹，绘制在坦克和弹体之下 | 每 2 帧 1 枚；普通暗橙 6 帧，穿甲白黄 8 帧 |
| 有效命中 | 90ms 短促中弹声 + 14×14 小爆闪 + 6 枚方向火花 + 局部闪白 | 爆闪 12 帧，火花 8～12 帧；普通 AI 命中不震屏 |
| 无敌吸收 | 青白小环，不扣血、不加分 | 6 帧，半径 8→13 |
| 淘汰 | 320ms 低频爆燃声 + 30×30 主爆炸 + 12 枚橙红余烬 | 主爆炸 24 帧，余烬 14～24 帧；可见淘汰震屏 6 帧 / 最高 4px |
| 玩家被击中 | 普通命中或淘汰表现 + 局部震屏 | 非致命受击 4 帧 / 最高 3px，逐帧衰减 |
| 砖墙被击毁 | 砖块白闪 + 6 枚砖红碎屑 | 碎屑 12～18 帧；子弹、扇形、冲击波、疾冲共用 |
| 钢板命中 | 4 枚灰白火花，钢板不损坏 | 6～10 帧 |
| 子弹互消 | 两弹中点白黄小闪光 | 6 帧 |
| 道具拾取 | 加血绿 / 火力黄 / 护盾青小环 + 4 枚像素点 | 12 帧 |
| 毒圈每跳 | 红色向外粒子；致命时升级为淘汰爆燃 | 8 枚 / 10 帧 |
| 出生/受击/护盾无敌 | 坦克常显 + 29×29 青蓝护盾环，仅环体呼吸与结束提示 | 20 帧呼吸；最后 12 帧每 3 帧明暗切换；出生 120 帧 / 受击 30 帧 / 护盾 300 帧 |
| 对手头顶标识 | 红色 12 号字母 tag（A/B/C），坦克上方 22px（避让血条）；可在设置中关闭 | 当前实现 |
| 坦克头顶血条 | 坦克上方 6px，26×3 连续比例条；玩家绿、AI 红，底色 `(60,60,66)`，填充宽度为 `round(26 × hp / max_hp)` | v2.3 |
| 空地地面 | 微噪点纹理（近黑底 (14,14,18) + (22,22,28) 稀疏点），预拼整张 416×416 每帧 1 次 blit | v1.9 |
| 河流 | 0.5s 双帧波纹流动（两帧波纹相位错 2px + 深水点），仅表现层 | v1.9（竞技场未使用） |

**原则**：世界层依次绘制地形/道具/毒圈 → 尾迹/残影 → 坦克/护盾环/子弹 → 枪口/命中/碎屑/扩散环/爆炸 → 草地 → 战争迷雾 → 血条/弹匣/射程提示。所有反馈使用世界坐标并随 `CAMERA_ZOOM` 放大；粒子与残影分别不超过 240 / 12，暂停冻结、重开清空。护盾环读取剩余无敌帧、不消耗随机数，并受草地与迷雾遮挡。震屏只作用于战场层，HUD 不抖动；无全屏白闪、伤害飘字或持续低血闪屏。

| 元素 | 规格 |

### 7.2 草地（森林）绘制顺序（v2.2，对应 GDD v3.1 单向隐藏）

草地精灵**完全不透明**（alpha 255），靠"绘制顺序"实现"里面看得见外面、外面看不见里面"：

| 玩家位置 | 绘制顺序 |
|---|---|
| 玩家**在草地内** | 地形 → **草地** → 尾迹/残影 → 坦克/子弹 → 上层特效 → 迷雾 → 血条/tag：玩家与可见 AI 都显示（藏身者的特权视野） |
| 玩家**在草地外** | 地形 → 尾迹/残影 → 坦克/子弹 → 上层特效 → **草地** → 迷雾 → 可见者血条/tag：草内坦克与特效均被遮住 |

> 与渲染同步，`env.build_foe_state` 对 AI 观测做同样的掩码：观察者不在草地时，草地里的对手从对手槽隐去——**视觉与信息严格一致**，不存在"看着不见但 AI 知道你在哪"。
> 注意：草地覆盖层只画在战场层（y ≥ 48），不得盖住 HUD。
